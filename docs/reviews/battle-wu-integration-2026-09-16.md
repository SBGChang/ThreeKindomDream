# 兵種、戰法與吳國整合

本次是可玩的初版整合，不代表長線平衡已完成校準。

- 戰前編成：步兵 0–100%，UI 每格 5%，預設 60%；四捨五入步兵數，餘數全部歸弓兵。出陣後凍結。
- 每隊最多 50 人，兩兵種各自形成不足 50 人的小隊。步兵前排接敵；弓兵在射程內射擊、接敵後停射後撤，後撤有戰場邊界。
- 弓兵使用既有 `public/art/units/sequences-v2/volley-atlas.png` 八格序列圖。沒有引用 UnitRigArt 或骨架版；第六格放箭，命中依模型判定。
- 25 個戰法加入作者資料與三國名士授業。舊技能 ID 保留給舊存檔與既有劇情授業。新戰法 Lv2–5 提升傷害／缩短冷卻；技能預覽與戰鬥共用解析器。
- 12 個條件觸發特性接入主角啟用欄與同行指揮。觸發時顯示持有者姓名；高等級提升持續時間或觸發率／冷卻縮減。
- 改編不增減人數；招降不算擊殺薪資；援軍和招降兵於本關離場，不計入本軍損失或永久兵量。調虎離山中的兵仍計入敵軍總量。
- 吳國包包含 8 章、12 位名士、7 關制戰役與 2 個改命結局，連同共通篇共 72 次行動。
- 孫策：U2.A 情報網 + U3.A 護衛 + 第五關，才能接回；U3.B 交接才有雙璧同舟結局。
- 朝議：U7.A 議事程序 + U7.B 輔政 + U8.A 朝議護送 + 第五關，才能接通；U8.B 公布交接才有江東共曉結局。
- `npm run sim:fast -- 10 flag-chaser` 已走正式 Session 的即時戰役、技能與單挑指令。舊版批次算式留作 legacy 相容比較，數據不可混為同一條平衡基準。
- 舊即時存檔保留已上場兵種為步兵，不在戰鬥中重新編成；新出陣才使用比例設定。

## 美術界線

沿用所有既有序列圖；孫權、周瑜、甘寧半身圖由使用者指定的 GreetingsMyLord 素材直接拷貝。尚無專屬單挑圖的吳國人物在作者資料明訂 `duelArtId: npc_soldier`，使用通用單挑序列；這些角色的專屬立繪和單挑美術仍需另補。技能演出沿用現有五類序列／粒子表現，尚不是每招各自一套新美術。
