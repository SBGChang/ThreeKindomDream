# Demo 美術精修
依使用者四張標註圖及原認可稿調整，正式素材目錄為 public/art/ui/demo-match/。
完整提示詞與來源：demo-match-prompts.json。使用內建 image_gen，未使用 API CLI。

- 行動卡：重畫無底部資訊帶版本，只保留圖案及名稱；移除頭像、數值與令／緣文字。
- 參與者：專用羊皮紙與酒紅墨暈底、人物漸隱邊、大型黑金凹槽及綠色亮面好感條。
- 好感：不顯示數字／階級文字。陌生為暗珊瑚握手、相識為珊瑚紅、友好為金色、知交為綠、最高階為青綠發光。實際色階依既有 stageOf，無自訂門檻。
- 事件／委託：對話驚嘆號和封蠟卷軸；存在時亮色，不存在時灰暗。保留 aria-label 及 hover title。
- 能力：四款專用雕刻圖章、彩色紋理、金屬凹槽、大尺寸亮面條；白色能力值與奶金預期增量皆有深色描邊。
- 官職：文官／武官名稱與目前官階、專屬圖案、右箭頭。整列可點擊，原功績資料仍保留於官階詳細資料。
- 底列：專用紅色章節旗、地圖、中央黑金學習點槽、書／箱／齒輪按鈕，配合即時資料定位。

驗證：production build 通過；浏览器核對全畫面；實測選中讀書顯示三位真正參與者、官職列可開關。
