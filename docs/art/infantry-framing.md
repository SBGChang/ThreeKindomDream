# 步兵動作比例修正

跑步與待機使用不同圖集。原始跑步可見高度為我軍 168–180px、敵軍 171–182px，待機分別為 137px、140px；原繪製器直接使用同一個方框大小，走停時因此出現約四分之一的尺寸跳變。

`src/ui/battle-sprite-framing.ts` 統一對敵我跑步套用 0.8 等比例縮放，整個跑步循環固定同一比例。依 32 幀的實際靴底位置，將落腳錨點對齊既有 slash/hurt 的 214/256 基準，消除跑步各列素材排版的垂直偏移。不依刀光、武器或倒地外框逐幀縮放。

正式 `realtime-battle-render.ts` 的共用 sprite 函式套用此矩形校正，因此一般交戰、撤退、走停切換、技能演出的跑步進退場都使用相同設定。弓兵、騎兵、武將與其他動作圖集維持原比例。原始圖檔不修改。

## 驗證

- `npm run typecheck` 與 `npm run verify:realtime` 通過。
- 新增步兵比例回歸測試，涵蓋兩軍 32 幀落脚對齊、不同縱深及技能尺寸、等比例繪製與其他圖集不變。
- 依既有不透明外框量測，修正後跑步高度相對待機的差異小於 6%，保留姿勢自身變化。
- `/battle-size-review.html` 使用正式共用比例函式，並排顯示敵我待機、跑步、揮刀、受擊及連續切換，已於瀏覽器視覺檢查。

若重新匯入或更換 run 圖集，需要重新量測腳底資料並校驗比例。
