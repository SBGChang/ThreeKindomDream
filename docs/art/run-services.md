# 行旅功能頁（訓練／商店／器物）

- 保留當前場景與原紅金底列；`RunWorkspace` 讓主行動畫面保持掛載，HUD 依方向滑出並設為 inert。返回恢復原行動預覽，不消耗回合。
- 底列 sprite 移到獨立 `.footer-art`，Hover／鍵盤焦點／選中只顯示金色外框。再次點目前功能或按 Esc／返回可關閉。
- 訓練：技能、特性分類，六門課程一頁，右頁顯示效果倍率、升級條件、費用與特性啟停。
- 商店：三件道具一架，指定碎片改為圖像選擇與確認訂購，沿用本章固定商品及限購規則。
- 器物：八格收藏一頁，本輪持有與待結算碎片分開查看；右側放大器物與有效階級。高階效果分頁完整顯示。
- 移除三頁原本的滿版通用紙框、重複金錢、上方章節列與另一組底部導航。訓練營的介面名稱統一為「訓練」。

## 獨立驗收

僅開發模式可用，不讀寫玩家存檔：

- `?art=layout`：空庫、金錢不足、多名同行；預覽文務後開關功能頁，仍保留預览及回合。
- `?art=economy`：6000 錢，可驗證商品購買、指定碎片、學習升級及特性啟停。
- `?art=economy&stock=full`：13 件器物與碎片、最高階效果，驗證收藏及效果分頁。

已以實際瀏覽器檢查上述操作、原場景保留、底列數值更新與無重複導航。
