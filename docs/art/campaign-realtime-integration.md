# 出戰整備與即時戰役接入

2026-09-14。已同步 `main` 的 `e9dfb45`，保留使用者確認的矩形看板、整合標題與兩個配置 Tab。使用者取消推回 main，改要求將 60 秒即時戰鬥、連續波次、養成配置及結算一起接入；本次未推送。

## 正式流程

整軍出陣 → 60 秒有效交戰 → 擊破後自動追擊下一波 → 鳴金或敗退 → 戰役結算 → 返回章末營地。新出陣不再呼叫舊版 `Session.engage()` 預先算完七關戰報。

- 訓練入口顯示 `Session.money`，開啟新版金錢訓練頁。
- 右側顯示倒數時限、首批敵軍波次、各波實際兵量與整波金錢；後續援軍持續抵達。敵人兵量與頭目取自章節戰役資料。
- 主角三招、同行三位與各自支援招式，直接成為戰場的 1／2／3、Q／W／E 操作。外層維持精簡資訊；技能選擇面板顯示實際即時效果、軍糧成本及冷卻。
- 官階及效果決定初始兵糧；四維、技能等級與既有傷害／恢復效果決定戰法強度。軍糧回復、各類戰法成本與冷卻放在 `battleRule.realtime`，可由內容層調整。
- 物理、計攻、恢復、強化、削弱各自結算，恢復不會誤傷敵軍。既有大檢定再起次數可在我軍耗盡時消耗一次，不重置倒數與敵軍。
- 保留新版入場、拉遠、Start、騎馬下令、技能演出、敗退、歡呼、追擊及黑場換波。所有過場凍結有效時間；換波延續兵力、軍糧、CD 與增益。

## 結算與存檔

- 完整擊破一波取得該波金錢、四維成長及特殊獎勵；未擊破波次依實際擊退兵數比例取得金錢。
- 第八波起沿用末波敵軍及金錢／成長；特殊解鎖與掉落只在原定波次給予，不無限複製。
- 敗退沿用獎勵減半。點擊返回營地時經 Session 原有獎勵與章末收尾入帳；重複結算被拒絕。
- 即時兵力、位置、波次、CD、軍糧及演出進度都在戰役存檔中。每秒及操作時保存；切到背景暫停，載入進行中的戰役也先暫停。已完成的戰鬥載入後仍是待領結果。
- 載入驗證即時狀態與波次資料，避免不合法資料進入倒數或結算迴圈。
- 已有舊版勝利戰報的存檔，完成其原本的走留決策；新出陣一律進入即時流程。

## 素材與數值界線

使用 main 的新版士兵與將領圖集；已有騎馬演出的角色沿用完整動畫，其他已配置名士暫用其本人既有角色圖呈現，不冒用另一位名士。各技能先依作用類型對應現有演出；尚未為全部招式新畫專屬動畫。

本次完成流程與資料接線。CD、軍糧與即時攻擊轉換使用初版設定，並非已完成整輪平衡。同行支援改為手動施放，星階仍決定可選招式；原先好感傳令機率不再宣稱是即時操作規則。

## 驗收

- 獨立入口 `/?art=campaign&sample=full` 使用正式元件及 Session，完全不讀寫玩家存檔；可從整備、訓練、戰鬥一路進入正式章末營地。
- 實際點擊出陣、施放萬人敵、破陣換波、敗退結算，確認 15 錢入帳一次並進入營地。
- 高官階樣本確認四維 100、四位數兵糧與末章波次情報沒有凸框。
- `scripts/tests/realtime-campaign.test.ts` 驗證真實配置、五類戰法、施招防重入、存檔續戰、換波延續、60 秒截止、敗退、一次入帳、章末休整、錯誤存檔及第八波獎勵。
- `npm run verify` 納入新版原始戰鬥測試與正式接入測試。
