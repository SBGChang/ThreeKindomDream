# 即時大檢定 Demo

入口：`http://127.0.0.1:5194/?art=battle-demo`。動作試映頁也有入口。獨立試玩，不讀寫正式養成存檔。

## 已實作

- 60 秒有效戰鬥時間，到時立即固定結算；我軍耗盡則停表，完整播放敗退與敵軍追擊後提前結算。
- 出陣可選 200／400／600 人。每個娃娃承載最多 50 人；內部 HP 就是存活人數，不顯示頭頂血條或数字。剩 1 人仍存活，0 人才倒地，依白→紅→黃交替閃光、淡出退場。
- 雙方步兵自動跑步移動、尋敵、揮刀、受擊；依地面深度縮放、前後遮擋。每波固定 600 敵兵，波內不補兵；目標鎖定至倒下，後排站定等待，跑步降低至 14 fps，近身揮刀一次 0.8 秒，減少反覆換姿勢和碰撞抖動。
- 我方資訊由左下向右，敵方資訊由右上向左。兩側总兵力條同一人數刻度，600 人長度為 400 人的 1.5 倍，剩餘兵力决定填充長度。
- 主角三招：火計／衝鋒／騎射。同行三招：郭嘉・夾擊／夏侯惇・衝鋒／于禁・鼓舞。按鈕與 1／2／3／Q／W／E 快捷鍵皆可施放，Space 暫停。
- 每招獨立 CD，扣軍糧後才施放，演出中不可重入。軍糧初始 160、上限 200，每有效戰鬥秒回復 2.4。
- 演出暫停普攻、倒數、CD、軍糧回復及增益時間；先聚焦該招將領騎馬下令（1.3 秒）→我方步兵淡出→壓暗聚焦→技能演出→命中定格／鏡頭返回→步兵淡入→恢復。火計追蹤引線，騎射追箭，衝鋒跟隨騎兵，夾擊拉遠前後合圍。鼓舞聚焦後方敲鼓、回場歡呼两次、攻擊提升 50% 持續 10 秒。
- 波次狀態機：我軍入場 2.6 秒 → 拉遠 1.25 秒 → Start 顯示並消退 1.45 秒 → 雙方起跑且倒數恢復。全滅當刻停表 → 倒地／閃光 1.9 秒 → 聚焦敗將並跟拍逃跑 3 秒 → 拉回勝軍、歡呼 2.3 秒 → 全軍快速向勝利方向跑出鏡頭 → 壓黑 0.65 秒 → 下一波淡入 0.65 秒 → 重新入場。
- 換波保留我方存活人數、軍糧、CD、特性及增益剩餘時間，不補血、不補兵；只有黑場換波時生成下一支完整敵軍。所有過場均凍結有效戰鬥時間。
- 主角、夏侯惇、郭嘉、于禁騎馬留在我軍最後排；敵方使用紅甲大眾臉指揮官。將領只演出指揮／歡呼／移動，不參加普攻或承載士兵 HP。敗方全滅後其將領逃跑；我軍全滅亦有對稱敗退演出。
- 即時特性示例「背水」：我軍兵力低於初始六成時觸發一次，8 秒內減傷 25%。
- 切離頁面自動暫停，避免背景結算。

## 驗收與界線

`npx tsx scripts/tests/realtime-battle.test.ts` 驗證編隊上限、死亡門檻、技能一次結算、CD／軍糧、防重入、鼓舞到期、暫停、傷亡守恆、60 秒到時停止及全滅退場；正式建置通過。瀏覽器檢查整備、交戰、六招演出與軍糧扣除，並修正夾擊拉遠後的背景缺邊。

此版為玩法及演出 Demo，數值尚非正式平衡。我方已具名四位將領、敵方為大眾臉指揮官；未串養成技能與軍力，也尚未加入正式音效。生成影格細節仍有些差異，可依試玩回饋繼續調整節奏、密度與特效。
