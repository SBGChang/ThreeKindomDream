# 三組單位動作試作

入口：`?art=unit-motion`，開發與正式預覽皆可開啟，不讀寫遊戲存檔。

這是程式原生 SVG 分件與父子座標骨架的可操作原型，並非 Spine 編輯器輸出的專案或 runtime。目的先檢查使用者指出的接合問題，再評估是否製作正式點陣分件與匯入 Spine。沒有將完整人物 PNG 晃動當作關節動畫，也不使用先前生成的四格立繪硬裁接。

## 動作

- 騎兵衝鋒 3.6 秒：壓低重心、五段左右的疾馳步態、收韁減速、落蹄。騎手骨盆以馬鞍為父座標，武器以握持點為父座標；馬匹四腿各有兩段骨骼、前後層次與錯相。
- 工兵點火 5 秒：持火、屈膝俯身、接觸引線、引線點燃、收手、起身。双腳保持固定落點，另一膝下沉；火把不隨意脫離手掌。只畫小火苗與引線，保留關節可見性。
- 弓箭手射箭 3.6 秒：搭箭舉弓、拉弦、瞄準、放箭、弓弦回彈、收勢。弓柄跟隨握弓手，弦的拉點跟隨拉弦手，箭尾從實際拉弦點出發；弓身在拉弦時略作彎曲。

## 分件與遮擋

共用頭盔、臉、軀幹、肩甲、上臂、護腕、手、裙甲、腿與鞋。每段素材在關節端點保留重疊區，肢長固定，以兩段 IK 計算肘／膝；端點不可達時限制距離，不拉長圖片。

馬匹另有軀幹、頸頭、尾巴、鞍墊與四條腿；騎手與馬匹同步起伏。所有 SVG 筆畫、配色與漸層由 `UnitRigArt.tsx` 定義，屬可修改的原生美術，不是 imagegen 點陣輸出。

## 驗收操作

預設暫停，單次播放不自動循環。可切換 0.25×／0.5×／1×、30fps 前後逐格、60fps 時間軸，以及關鍵姿勢跳轉。切換動作會回到第一格。提供深淺底、格線、骨架與戰場大小／原尺寸／放大檢查，切走頁面自動暫停。

執行 `npx tsx scripts/tests/unit-motion.test.ts`，檢查肢長、雙手握點、弦與手一致、腳掌固定、點火時間與接觸高度、收勢。視覺仍需看播放與關鍵格，不能只靠數學檢查宣稱正式美術完成。

## 此版邊界

單位在原地演示，不含鏡頭追焦、兩軍廝殺、技能 CD、軍糧、結算。未製作轉身、多視角或完整馬術力學；正式量產前應先確認動作風格和關節表現。
