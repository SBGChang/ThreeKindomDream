# 入夢與圖示控制

入夢頁正式改成四區單頁：資質、天賦、隨身器物、同行。使用現有養成宣紙木框、圖示與角色素材。保留草稿成本、上限、可帶數量與 validateDraft；超支時顯示必要原因並禁止入夢。

ArtControl 統一 X、返回箭頭及書本按鈕；保留 aria-label 與 tooltip。名士詳情改成完整立繪、角色名、上司／同行、彩色握手好感槽、專長、書本修習入口，不顯示多餘好感數字與說明段落。

遊戲範圍隱藏所有原生捲軸。useDragScroll 支援滑鼠按住拖動可捲動區域，位移超過 7px 才啟動，拖曳結束抑制誤點；保留一般點擊、滾輪、鍵盤與觸控原生捲動。

驗收頁 /?art=realms&view=entry 使用記憶體副本，不寫入存檔。

驗證：資質 C 導致超支時入夢停用；名士詳情 X 關閉及焦點歸還；名士清單拖動後選取不變，下一次點擊正常；入夢四區與確認按鈕皆在畫面內。
