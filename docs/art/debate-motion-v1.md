## 郭嘉生成提示

Production 2D game CHARACTER ANIMATION SPRITE SHEET, NOT UI icons. Reference image is Guo Jia identity/costume/style reference only. Generate full-body ON FOOT Guo Jia in same blue-white scholar robes, blue jade crown, long dark hair, chibi hand-painted outlined Three Kingdoms style. Exactly 4 COLUMNS by 8 ROWS, 32 separate full-body sprites, uniform invisible grid, canvas 1536x3072 (each cell 384x384). Every sprite faces RIGHT three-quarter view, feet at same baseline 88% of each cell, same scale with head-to-foot height about 78% of cell, ample clear margin, never cross cell boundaries. Pure flat chroma-key MAGENTA #ff00ff background everywhere outside characters, no shadows, no gradients, no text, no cell lines. No horse, no sword, no battle attack. Row 1: CLAIM debate gesture: hold closed bamboo slips, unfold bamboo slips, present open slips in left hand and explain with raised right palm, lower slips. Row 2: PROOF: take paper scroll from sleeve, unroll it, decisively hold open evidence scroll toward opponent, lower scroll. Row 3: QUESTION: pondering with index near chin, lean slightly forward, point accusingly toward right, retract pointing hand. Row 4: REBUT: draw sleeve inward, raise open palm, sweep sleeve and rejecting palm toward right with firm expression, recover. Row 5: BORROW: open both hands, circle gesturing hand, beckon confidently toward self with knowing smile, recover. Row 6: FOCUS: hands lower, close eyes hands folded at abdomen, deep calm breath shoulders lowered, open eyes. Row 7: PRESSURE: brace feet clenched fist at chest, lean forward open mouth, command loudly right with decisive open palm, recover. Row 8: four subtle IDLE breathing poses with hands at waist, no props. Each row is four consecutive distinct keyframes of its described command. Keep identical identity, costume, proportions and baseline across all 32 frames. Frame 4 returns towards neutral. Exact grid is essential for automated slicing.
