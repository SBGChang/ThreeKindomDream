# 關卡軍情 v10

外層移除「迎敵軍情」、秒數、姓名、金錢、掉落與無限援軍裝飾，只保留七關軍旗編號、敵方頭像、兵數。每列由 40px 增為 54px，間隔 2px；軍旗、頭像、數值分為固定欄位，不再疊在彼此上方。沒有指定敵將的波次使用一般士兵頭像，不虛構主將姓名。

內頁改用新繪製的軍情卷軸：左側完整敵將立繪與關卡短述，右側分區顯示真實兵力、全戰役交戰時間、本關金錢與特殊戰利品。金錢註明按擊退比例結算，特殊戰利品僅在該關存在時顯示。下方以三句保留連續援軍、倒數／補給及結算規則，確認按鈕為「確定」。

兩張新素材均使用內建 image_gen，原始 PNG 保留並複製至專案，角落 alpha 為 0。完整提示詞及素材路徑見 [素材紀錄](campaign-wave-v10-prompts.json)。清單與詳情讀取同一份 Session 關卡預覽資料，沒有變更戰鬥玩法。

驗收：完整配置的一般與特殊關卡、後期七關四位數兵力、七關逐一開啟與返回、關閉後焦點恢復、內頁文字區邊界。TypeScript、紀律門禁與正式建置通過；既有 bundle 大小提示保留。
