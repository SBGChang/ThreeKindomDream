# 純臉部 50% 與臉部中心置中

## 統一規則

臉部中心固定在方格正中心（50%、50%）。尺寸只量額頭到下巴的臉部平面，包含五官，但不含頭髮、頭盔、頭飾、耳朵或下巴以外延伸的長鬍鬚。臉寬與臉高都不超過畫面的 50%，較長一邊恰為 50%，另一邊保持原比例；不拉伸五官。畫框仍取自完整立繪，肩膀與衣服自然入鏡，帽子、髮型和衣服可被裁切。

所有角色與所有介面使用同一組 `PORTRAIT_RULE`，位於 `src/ui/portrait-layouts.ts`。已移除逐人／逐場景的輸出位置與縮放覆寫。

## 角色資料

`src/ui/character-framing.json` 每人記錄：

- `source`：實際使用的原圖。
- `face: {x, y, width, height}`：純臉部矩形。X 與 width 除以原圖寬，Y 與 height 除以原圖高。
- `sourceRegion`：僅圖集需要，限制在該人物的單一動作格內，避免相鄰格漏入。
- `generation`：素材批次。

舊的含帽子 `head` 框和人工微調 `focus` 已移除。更換圖片必須重新量測 face。臉框從各角色的實際圖片量測，不由頭髮框推算。

## 裁切公式

設原圖尺寸為 W × H，`side = max(face.width * W / 0.5, face.height * H / 0.5)`。

方形原圖取景範圍：`x = (face.x + face.width / 2) * W - side / 2`、`y = (face.y + face.height / 2) * H - side / 2`、`width = height = side`。等比例映射至 256 × 256 輸出，臉部中心即在 (128,128)。不因帽子或武器更改定位；超出圖片的區域保留透明，不把框推回而導致臉部中心移位。

## 預覽

`?art=gallery` 的原圖黃框標示純臉部、紅十字標示臉部中心、青框標示取景。頭像成品的黃框是同一純臉部範圍的映射，中央紅點標示臉部中心；中心線供比對。勾選「只看頭像」看全員占比，取消導線看正式外觀。關羽與張飛現在按純臉部比較，頭盔、頭髮、鬍鬚都不影響縮放倍率。
