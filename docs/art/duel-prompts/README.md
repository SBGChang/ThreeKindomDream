# 單挑素材交接

內建 image_gen 生成整張騎乘序列，角色身份參照既有 `characters-v2`，未拆成肢體骨架。

- 基本動作提示與人物參照：`source-manifest.json`。
- 夏侯淵新增身份：`xiahouyuan.txt`。
- 排列修訂提示：`revisions.txt`。
- 獨立 UI 提示：`ui-kit.txt`、`status-scroll.txt`。
- 正式角色名冊：`src/contracts/core/duel-art.ts`。
- 正式版本與來源欄數：`src/ui/duel-art.ts`；主角、陣營指揮官、審配、司馬懿、張飛、張遼使用 v2，其餘 v1。舊 v1 留作生成歷程，未載入。

基本來源為四欄八列，攻、防、休、受擊依序各八格。郭嘉／華雄來源為八欄八列，取來源第 1、3、5、7 列，各自八格，避免把同一動作的額外影格誤當成下一動作。輸出統一為四欄八列的 256px 單格 atlas，不拉伸。

角色來源以洋紅平底供遊戲載入時去背；狀態卷軸本身有 alpha。載入流程去除洋紅邊、保留每格完整騎乘輪廓，排除鄰格孤立碎片，並固定馬蹄落地基線。單格仍使用原圖比例，沒有肢體拼接。

驗收入口 `?art=duel-motion`：38 個身份、每頁八個，可切換四個動作、播放一次或拖曳八個影格，另有深／淺背景。五頁已逐頁查看，並在實際對戰檢查攻擊／受擊、令牌與歷史顯示。`scripts/tests/duel-art.test.ts` 會防止正式人物及有名敵將缺少素材。
