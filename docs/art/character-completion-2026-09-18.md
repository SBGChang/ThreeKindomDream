## 畫風與接線

- 以既有曹操立繪為新增角色的比例與線條參考，維持大頭短身、粗輪廓、簡化色塊；角色動作再依各自立繪延伸。
- 早期過度寫實、身體比例偏長或沿用錯誤臉孔的試稿均未接入遊戲。
- 新蜀將移除 `npc_soldier` 暫用設定；許攸新增登錄；夏侯淵改用獨立立繪。
- 舌戰依實際選角或劇情對手載入專屬站姿圖集，頭像、姓名及身體一致；載入完成前鎖定出牌。
- 頭像使用共用臉部置中規則；序列統一腳底基準與比例，避免相鄰格滲入。
- 美術演武頁新增舌戰模式，可選七種動作及待機。

## 驗收

- `npm run verify` 通過：型別、紀律、內容、模組、戰場、單挑、舌戰、頭像、劇情與角色素材覆蓋。
- `npm run build` 通過；仍有既有大型 bundle 提示。
- 新增具名角色不得借用士兵素材、立繪／舌戰檔案不得重複的檢查；加入舌戰實際繪製指定角色的回歸測試。
- 瀏覽器抽查：新增角色立繪總覽、馬超單挑及指揮、馬超與劉備舌戰裁切、馬超對法正的實際舌戰頭像與身體。
