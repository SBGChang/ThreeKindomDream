# 出戰整備 v1

2026-09-14。依 three-kingdom-ui 原則、入夢 aptitude-v2 場景構圖、養成 record-board-v2 能力板與 name-card-v2 名帖重製。這是已接入的改版，仍待使用者評價風格。

## 版面與互動

- 1280 × 800 軍營整備場景；左側依文武官階顯示主角，四維與有槽感的兵糧條。
- 中央矩形看板以「主將招式／同行指揮」Tab 呈現三招或三位指揮。招式、編隊與每人的支援招式分別開啟選擇面板；超過六項分頁，主畫面不滾動。
- 指揮名帖使用人物、握手與好感槽；詳細編隊面板顯示實際傳令機率與無可用招式原因。
- 右側七關路線從 Session.stageRows() 讀取關底敵將、累計學習點與特殊掉落標記。
- 獨立書本入口進入戰前修習，返回保留草稿；出陣按鈕沿用 configureCampaign → CampaignJourney，出陣後凍結配置。
- 無名士時收起三張空人物框；未攜帶主將招式時提示，保留原有允許空配置的規則。
- 選擇面板限制焦點範圍、背景 inert，Esc 關閉並回到開啟按鈕。

## 驗收入口

啟動開發服務後使用 `/?art=campaign&sample=full`。同一份正式 ScreenCampaign 與 Session，驗收頁不讀取／寫入玩家存檔。

- `sample=full`：全部招式、六位可選指揮，用於分頁、三人限制與更換驗收。
- `sample=single`：一招與一位指揮。
- `sample=empty`：無招式與無指揮。
- `sample=veteran`：最高官階、四維 100、末章路線與較長兵糧數字。
