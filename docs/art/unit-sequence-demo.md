# 六格單位動作序列 v1

使用者否決前一版原生 SVG 骨架的外觀，指定沿用藍羽盔、金邊深藍甲的 Q 版立繪。本版採內建 imagegen 製作三組六格序列，動作由逐張 PNG 播放，不以骨架變形、混合淡入或移動整張立繪替代姿勢變化。

入口：`?art=unit-sequence`；原 `?art=unit-motion` 也改為本版。前版另留於 `?art=unit-rig` 供比較。獨立展示頁不讀寫玩家存檔。

| 動作 | 六格內容 | 1× 循環時間 |
|---|---|---|
| 騎兵衝鋒 | 伸展、前蹄落地、收攏、蹬地、伸展、銜接 | 0.72 秒 |
| 工兵點火 | 持火、屈膝、觸地、燃起、收手、回起手 | 1.50 秒 |
| 弓箭手射箭 | 搭箭、舉弓、瞄準、放箭、取箭、重新搭箭 | 1.20 秒 |

## 正式接入素材

- `public/art/units/sequences/charge/01.png` 至 `06.png`
- `public/art/units/sequences/ignite/01.png` 至 `06.png`
- `public/art/units/sequences/volley/01.png` 至 `06.png`
- 對應三張 `public/art/units/sequences/{charge,ignite,volley}-six-v1.png`

每張獨立影格 576×576，圖集 1728×1152（3×2），RGBA 真透明。人物固定比例，不將每張各自縮放填滿，避免蹲下時反而變大。工兵依前腳、弓手依雙脚對位；騎兵依頭部基準保留小幅上下起伏。第六張循環回第一張，不額外重複第一張充數。

原始生成底稿錯把棋盤格畫進背景，故再次透過 imagegen 改成色鍵底稿；`scripts/prepare-unit-sequences.ps1` 在素材匯入階段解碼色鍵、抑制綠邊、補透明安全邊距及拆出單格，不改畫人物。原始色鍵圖存於 `docs/art/sources/unit-sequences/`，完整生成與修正提示詞見 [unit-sequence-prompts.json](unit-sequence-prompts.json)。未採用 CLI 圖像生成。

## 播放與驗收

預先載入完整六格後才開始播放，以免首播閃圖。預設循環，提供暫停、前後逐格、0.25×／0.5×／1×／1.5×、單次播放、深淺底／營地、戰場比例。逐格區可直接點選姿勢；每組可下載圖集。切换到同一動作可重新起播；切離分頁會暫停。

檢查 18 張影格的透明邊界與尺寸、6→1 回接、暫停逐格、三組載入、單次停止、深淺底及武器／火苗完整性。這仍是六格動作試作；尚未接入實際戰鬥、命中事件或技能結算。生成素材的小裝飾差異不應冒充骨架級別的完全一致。
