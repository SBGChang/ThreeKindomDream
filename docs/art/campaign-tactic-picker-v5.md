# 戰法選擇冊 v5

使用者否決原本的文字卡片式選擇彈窗。本版以獨立攤開戰法冊取代：左頁每頁六個插畫／名稱選項，右頁集中展示所選戰法的大圖、等級、效果、軍糧與冷卻。下方為出戰位置及完成入口，移除重复的卡片說明與整段通用戰鬥規則。

- 新背景及火計、水淹、連環計插畫使用內建 image_gen 製作，保存原始 PNG，確認透明 alpha。素材路徑與完整提示詞：[campaign-tactic-picker-v5-prompts.json](campaign-tactic-picker-v5-prompts.json)。
- 沿用 v4 的突陣、陷陣、萬人敵插畫；六招以外的戰法仍使用既有屬性圖示。共用 `TacticArt` 也讓外層戰法卷同步顯示新插畫。
- 點選只預覽；「攜帶／卸下／替換」才改動配置。滿三招時，先選新招，再選下方替換位置，維持其他招式及順序、不產生重複招式。
- 支援招式沿用同一本選擇冊，限制一招，直接替換且不可清空指揮的必選支援。效果仍讀取該名指揮的即時戰法數值。
- 點外層招式時直接預覽該招；下方點已攜帶招式會翻至對應頁。保留關閉焦點返回、Tab 焦點限制、背景 inert 與鍵盤操作。

驗收：獨立且不寫入玩家存檔的完整配置測試，預覽不改動配置、三招替換、卸下再補位、翻頁／強化效果、支援單招替換、空白配置及訓練入口。TypeScript、檔案紀律及正式建置通過；既有大型 bundle 提示保留。
