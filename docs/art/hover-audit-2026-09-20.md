# Hover 底圖巡檢（2026-09-20）

本次修正滑過後出現白色矩形、換錯底圖，以及聚焦／按下時重設底圖的問題。

## 原因與修正

- `player.css` 的全域 `button:hover:not(:disabled)` 以 `background` 簡寫覆蓋美術背景，也重設圖集位置與尺寸。改為低優先序的亮度回饋。
- `game.css`、`art.css` 的共用 Hover 不再重新指定背景，保留元件自己的美術。
- `battle-hud.css` 的共用按鈕基礎樣式不再於 Hover／focus-visible／active 重套；暫停、戰況與狀態效果可保留自己的底圖和字色。
- `treasury-codex.css` 移除蓋掉紙製頁籤的舊純色 Hover，以及重複的選取底圖宣告。
- `event-challenge.css` 同樣將底圖限制於基礎樣式，避免「整備完成・出陣」聚焦／按下時由綠玉底圖變成紙底。

確認受影響的入口包括戰況、暫停、倒數、軍糧、戰場狀態效果、演武兵力選項、軍令、重新整軍、單挑入口、舌戰說明、天工閣「取得方式」，以及事件出陣按鈕。

## 驗收

使用正式元件的獨立驗收資料，沒有操作玩家存檔。

- 50 個畫面狀態、676 個控制項實例（包含不同畫面重複出現的共用元件）。
- 檢查 Hover、focus-visible、active，以及按鈕子元素和偽元素的底圖、圖集位置、背景尺寸。
- 範圍包含戰鬥與暫停、狀態效果、出戰整備各頁籤、選將與戰法／援護配置、軍情、養成、訓練、商店、行囊、人物詳情、手記、系統設定／確認窗、入夢各頁籤與選人、圖鑑、單挑、舌戰、事件戰鬥和主選單。
- 實際操作戰況 Hover、鍵盤聚焦、按下，以及暫停／繼續。查看修正後的戰況、暫停與圖鑑頁籤截圖。
- 保留有意義的既有回饋，例如物品架淡金色提示、主選單亮光、舌戰特性光暈。
- 打包版本另外複驗 10 個畫面狀態、109 個控制項實例，全部通過。
- `npm run typecheck`、`npx vite build` 通過；建置仍有既有的 bundle 大小與混合靜態／動態匯入提示。

重跑方式（先啟動 Vite）：

```powershell
$env:PREVIEW_URL='http://127.0.0.1:5174'
node scripts/verify-hover.mjs
```

入夢選人為工作區中另外開發的驗收入口；該入口尚未加入的版本會略過這 4 個畫面狀態。

可用 `HOVER_SCREENS` 指定逗號分隔的入口名稱，或以 `PLAYWRIGHT_MODULE`、`PLAYWRIGHT_CHANNEL` 指定現有瀏覽器測試環境。

逐項報告與前後截圖位於 `artifacts/hover-audit/`。`verified.json` 為完整驗收結果；`production.json` 為打包版本的戰鬥、圖鑑、單挑複驗結果。
