# 官階造型與小劇場接入

素材：public/art/theater/career/。由內建 image_gen 生成，原始提示見 career-theater-prompts.json。

|階段|遊戲官階|武職／文職|
|---|---|---|
|白身|1（相容舊資料 0）|灰布新兵／素衣學徒|
|初階|2–3|皮甲小隊長／褐衣書吏|
|中階|4–7|銅甲軍官／青衣官員|
|高階|8–12|金甲將領／紫衣重臣|

四個屬性的行動、Hover 服装、小劇場由 career-presentation.ts 統一對應。文武官階各自讀取；播放先保存行動前官階，避免獎勵升階途中換裝。數值、事件抽選與存檔結構不變。

stage-0 至 stage-3：每張 4×4 格，列依序為軍務、演武、文務、農務；每列原有 4 張關鍵姿勢；正式播放只使用準備、動作、完成三張，排成 10 個時間節拍，1 秒演完一次並停在完成姿勢。捨棄回復起始姿勢的第四張，不再循環。低階主角接受通用長官指示，高階主角負責指揮。

wardrobe：4×2 格，上武下文，各列由白身至高階。
立繪取圖不能直接等分：中、高階披風與高階文官帽帶越過名義欄界。`CareerTheater.tsx` 的 `wardrobeBounds` 依兩版 1448px 寬圖集的實際透明間隔取圖，避免初階武將旁出現下一格的披風殘片；寬於單格的造型等比縮放、腳底對齊。已在 `/?art=career` 檢查初階至高階武將及中、高階文官。
frames：四種手繪外框；實際 1254×1254，上列 y=0..580，下列 y=584..1254，避免等分時混入鄰格。

正式演出 540×405（原 720×540 的 75%），介面向外推開，素材載入後開始計時 1000ms，再恢復介面並直接顯示結果（取消經驗成長動畫）。舊全畫面人物跳動／文字道具演出已從 TaskPerformance 與 CSS 移除，舊 inspection-loop 素材不再由程式引用。

驗收頁：/?art=career（相容 /?art=inspection），可切換階段、項目、重播與逐格，單次播放後保留完成姿勢供檢查。
