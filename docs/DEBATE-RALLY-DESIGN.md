# 輪流接牌舌戰：玩法與特性分配

目前實裝於 `?art=debate-demo`。取代這個入口的同時揭牌玩法；既有單挑與舊模型回歸測試保留。配法可套用 50 位武將，演出目前沿用郭嘉與敵軍指揮官兩套舌戰序列；這是特性試配，不會改寫戰役存檔或武將屬性。

## 規則

- 義理（藍）、事證（綠）、聲勢（紅）各 1–9 點。同色必須更高，同點可以換色；另起第一張任意。
- 我方先手。普通牌出完補一張並換手。每回合最多使用一張特殊牌，特殊牌效果結算後立即補一張普通點數牌、不換手。
- 普通牌與特殊牌皆無法使用時，自動跳過並抽一張；有牌可出就必須出牌，不能主動跳過。有普通牌可出時可選擇是否先用特殊牌；僅特殊牌可用時必須先使用。怒斥造成的跳過也補牌，且該回合不可使用特殊牌。
- 對手上一手跳過，自己繼續出普通牌時 Combo 增加 1，每點提高 20% 傷害。對手打出普通牌或另起時歸零；自己跳過也不保留連段。
- 雙方連續跳過後，兩方棄置整手、重新抽牌，由最後跳過者另起。重抽不回復心防，除非具有重整旗鼓。
- 雙倍傷害、反論、詭辯保留到下一次實際消耗，另起不清除。反論整次反彈，不再觸發另一層反論。反彈可以使出牌者落敗。
- 對手普通牌僅公開牌色，特殊牌統一顯示紫色紋章牌背；點數、特殊牌種類、內部 ID 與隨機狀態不進手牌顯示資料。AI 僅使用自己的手牌與公共牌面／狀態。
- 心防歸零結束，沒有選牌倒數與回合上限。

## 初版數值

- 智力 1–20／21–40／41–60／61–80／81–100：重抽 4／5／6／7／8 張。博聞額外一張普通牌。每次重抽前兩張保證普通牌。
- 每次一般抽牌，有主動特性時為 16% 機率從全部已擁有來源中等機率抽取特殊牌；否則必為普通牌。集中抽的三張亦遵循此規則。
- 三色等機率；點數以相同隨機分位隨智力單調提高。普通牌點数使用 1 + floor(9 × U^(1.65 − 0.011 × 智力))，最高 9。
- 基礎傷害為 5 + 0.11 × 智力 + 2.2 × 點數，再乘 Combo、怒斥與被動修正，最後四捨五入。政治提供心防：160 + round(0.6 × 政治)。公式只寫在設計文件，HUD 用閃爍血條預估。
- 武將智力與政治讀取既有 content 產物；無資料的試玩角色使用 65／65。

## 主動特性

| 特性 | 特殊牌 | 效果 |
|---|---|---|
| 融會貫通 | 歸納 | 選兩張普通牌，兩張都變為點數總和，最高 9；牌色不變。 |
| 當頭棒喝 | 怒斥 | 下一張普通牌傷害翻倍，對手下回合跳過並抽一張。 |
| 博覽強記 | 集中 | 立即抽三張牌。 |
| 以子之矛 | 反論 | 反彈下一次普通牌傷害，自己不受該次傷害。 |
| 奇辭巧辯 | 詭辯 | 下一張普通牌可無視牌色與點數限制。 |

## 被動特性

| 特性 | 效果 |
|---|---|
| 沉著 | 受到的傷害降低 10%。 |
| 雄辯 | 普通牌傷害提高 10%。 |
| 以小見大 | 1～3 點普通牌傷害提高 35%。 |
| 借題發揮 | 同點換色時傷害提高 25%。 |
| 乘勝追論 | 有 Combo 時額外提高 10% 傷害。 |
| 臨機應變 | 跳過時抽兩張普通牌，而非一張牌。 |
| 重整旗鼓 | 每次另起恢復 8 點心防。 |
| 博聞 | 初始及另起多抽一張普通牌。 |

## 分配原則

- 主動來源不設單一種類限制，有多少種主動特技就開放多少種特殊牌；被動維持最多兩項。沒有主動來源就不能抽特殊牌，不用被動變相發特殊牌。
- 諸葛亮、荀彧、張昭等以整理論據為主，配歸納；曹操、張飛、程昱等配怒斥；周瑜、陸遜、呂蒙、魯肅配集中；司馬懿、賈詡、審配等配反論；郭嘉、龐統、郭圖配詭辯。
- 郭嘉的詭辯搭配低點牌與換色收益；賈詡用反論與跳過補牌周旋；諸葛亮靠歸納及較多起手整理高點牌；張飛依靠怒斥與連段取得短時間優勢。
- 純武勇角色不普遍取得特殊牌。以乘勝、沉著、重整等普通牌被動區分，也保留完全無特性的基準角色。
- 這是玩法定位，不以智力高低一律給最強主動特性。初版模擬用於確認終局與規則一致性，尚不是最終平衡定案。

## 驗證與操作

執行 npm run verify:confrontation，包含五百場完成對局、27 種接牌組合、五種特殊牌、八項被動、反彈敗北、Combo 清除、歸納非法選取不改狀態、重抽、隱藏資訊、智力抽牌分布與武將數值來源檢查。

普通牌 Hover／鍵盤焦點顯示血條預估，點擊直接出牌。歸納是唯一需要選兩個目標的流程：點歸納、點第一張、滑過第二張看兩張新點數閃爍，點第二張執行。1–9 對應目前手牌；Escape 取消歸納或關閉說明（舌戰不設暫停）。手牌依牌色與點數排序，特殊牌置右，使用扇形重疊排列。
