# 蜀國篇：這一次，一個都別落下

設計稿；8 章、64 回合，接共通開場後為 72 回合。蜀線的成長是從「跟著一群沒地方去的人」，走到「有能力接住他們的夢」。熱血來自夥伴會回應你：你替他擋過一箭，他會在下一次軍鼓響起時站到你身邊。

## 角色與玩法辨識

| 人物 | 劇情位置 | 日常口吻／關係變化 | 可用名士方向提案 |
|---|---|---|---|
| 劉備 | 記得每個人的主公 | 問姓名、問家鄉；後段願意聽你的逆耳之言 | 統：集合、支援 |
| 關羽 | 從替你擋刀到願把後背交你 | 少說話、承諾必回；改命後第一次主動求援 | 武：突破、反擊 |
| 張飛 | 把你當自己人的前線大哥 | 大嗓門與精細準備並存，不靠羞辱部下搞笑 | 統／武：壓陣、護衛 |
| 趙雲 | 永遠多回頭看一次的人 | 先數回來多少人，才說自己打得如何 | 武：救援、保護 |
| 諸葛亮 | 肯把全局交給你的人 | 早期讓你答題，後期與你並肩補圖 | 智：接續、協同 |
| 龐統 | 會把漂亮計畫戳破的人 | 辛辣但願親自補洞；入蜀章以臨場方案塑造 | 智：奇策、突破 |
| 法正 | 知道機會在哪，也敢催你下手 | 對人情有記憶，對戰機極敏銳 | 智：先機 |
| 黃忠 | 讓年輕人收起輕視的老將 | 教你不要只看箭射多遠 | 武：蓄力、要害 |
| 魏延 | 想把路走得比誰都遠 | 與保守方案爭論，接受清楚的任務與權責 | 統：突進 |
| 蔣琬 | 接住下一棒的人 | 看似不搶話，卻總能把沒人做的事完成 | 政：後勤、交接 |
| 費禕 | 讓人願坐下來的人 | 用一句輕鬆話拆掉僵局 | 政：協調 |
| 姜維 | 後段的新一代 | 先追問你的勝仗，後追問你的撤退 | 統／智：接力 |

這是內容定位，不是 12 位角色數值已配妥的宣告。歷史人物的主線出場不要求抽中或升星；名士池只決定玩家可養成、可出戰的夥伴。

## S1｜虎牢相逢：沒有自己的營，也有自己的兄弟

ID 提案 `ch:shu.hulao`。R9–16。時間以討董的演義舞台呈現。

**入章。** 盟軍帳外，張飛正為分不到軍糧吵得滿臉通紅。劉備把自己的餅掰成幾份，連你的那份也算進去：「先吃。餓著，可守不住旗。」

**A｜輪不到的軍功。**

- 請戰救受困友軍（`rescue`）：你帶兵補入缺口，關羽抬刀與你並行：「跟好。」結果：記護民，保住友軍隊伍。
- 修整破損軍械（`repair`）：你把各營丟棄的兵器修成能用的傢伙。張飛試了槍，大笑：「這下不欠他們了！」結果：後勤／軍械路線前置。

**B｜沒人認領的傷兵。**

- 把傷兵記入自己名簿（`shelter`）：劉備看完，將名簿合上：「都算我們的。」結果：記護民。
- 教新隊長分段接防（`handover`）：你讓隊長輪流守旗，關羽第一次直接向他們交代任務；記交接。

**七關。** 關外亂兵 → 友軍缺口 → 華雄前陣 → 斷旗坡 → 西涼騎陣 → 呂布前鋒 → 呂布突擊。玩家協助救援與破陣，不取代關張的角色辨識。

**章末。** 夜裡四人圍著小小的火。劉備問你願不願同行。張飛搶著說：「飯都吃了，還問！」成果：隊伍多帶回一隊傷兵。代價：關羽替你截住追兵，手仍牢牢握住你的旗。全通：呂布止馬，讓出一線撤離空間，你與關張同時收住兵鋒。

## S2｜徐州風雨：我們總得有個家

ID `ch:shu.xuzhou`。R17–24。章內用蒙太奇交代徐州得失及依附流轉，不把陶謙、呂布與曹操衝突寫成同日。

**入章。** 城裡第一次有人喊你們「自家兵」。張飛高興得在地圖上圈出酒坊，趙雲卻先圈了井與城門：「守住這些，他們才喊得久。」

**A｜新領地的第一件事。**

- 修倉安置流民（`granary`）：你把可耕地與糧種一併造冊；記護民，仁政國策前置。
- 重整城防隊伍（`defend`）：你把新舊部曲編入共同守備；軍事國策前置。

**B｜守城失利，必須撤走。**

- 分路護送家眷（`shelter`）：你親自折返最後一條巷子，帶出困住的百姓；記護民。
- 讓年輕隊長領一支撤隊（`handover`）：你給他真實權責，趙雲護住另一翼；記交接。

**七關。** 城外哨營 → 糧道 → 城門爭奪 → 巷戰 → 家眷護送 → 追騎 → 突圍接應。

**章末。** 基線仍失去徐州。劉備望著離去的人潮，你把名簿交給他：「地方還能再找，這些人，我們帶出來了。」成果：隊伍保持秩序。代價：趙雲與你分隊找回失散者。全通：最後一輛車出城時，你把門栓打斷，截住追兵。

## S3｜長坂：回頭的那一騎

ID `ch:shu.changban`。R25–32。前半以新野落腳、三顧與荊州局勢交代隆中方向，再進入長坂。

**入章。** 諸葛亮第一次把地圖攤到你面前。你還沒聽完那個遙遠的天下，斥候已帶來追兵的消息。趙雲翻身上馬：「大的計畫先放著。眼前這些人，得先過河。」

**A｜道路被車隊堵死。**

- 折返接人（`rescue`）：你領步卒拆車架、架便橋，為趙雲留接應點；記護民。
- 奪側翼高地（`flank`）：你用旗號引走部分追騎，張飛得以縮短正面防線；軍事前置。

**B｜到渡口後。**

- 留舟接最後一隊（`shelter`）：劉備已催你登船，你把纜繩重新扣回樁上：「還有一隊。」記護民。
- 交新隊長維持渡序（`handover`）：你去接趙雲，他接住渡口；記交接。

**七關。** 村口散兵 → 廢車道 → 追騎 → 橋前陣 → 張飛側翼 → 渡口護送 → 趙雲歸途接應。

**章末。** 趙雲自煙塵中奔回，看見你留的旗，勒馬笑了一下：「就知道你在。」成果：最後一隊登舟。代價：船隊分散，在下游重新集合。全通：兩騎並肩壓住追兵，直到河面再無孤舟。

## S4｜赤壁借勢：有人願與我們同戰

ID `ch:shu.chibi`。R33–40。

**入章。** 江東帳上有人問，劉備還剩多少兵。你正要起身，魯肅先將兩張地圖推在一起：「先問，合在一起能做什麼。」諸葛亮朝你點頭。

**A｜聯軍約定。**

- 定下互援與通航約章（`pact`）：共同確認糧船、軍使與撤退通道，具體到旗號和停靠處。結果：D-S1 第一準備。
- 優先爭取己方作戰空間（`position`）：確保劉備軍有可立功的戰線。結果：軍事國策前置；維持普通聯盟。

**B｜火起時誰去接人。**

- 自領救援船隊（`shelter`）：你照盟約接起兩軍落水者；記護民。
- 讓兩軍副將共掌接應（`handover`）：一支旗令就能叫動兩家的舟船；記交接，培養跨營信任。

**七關。** 江口前哨 → 曹軍游舟 → 南岸營 → 火線側翼 → 聯軍接應 → 曹軍退道 → 江陵外圍。赤壁至江陵以時間字幕轉場。

**章末。** 你與江東兵把同一條船推上岸，誰也沒先問旗號。成果：兩家的傷兵同坐一灶。代價：撤離受阻，盟友返航接回你的部曲。全通：兩面旗一起插在岸上，後續荊州聯絡有了共同的記憶。

## S5｜入蜀：讓天下之計有一個落腳處

ID `ch:shu.yizhou`。R41–48。入蜀與成都收束合為一章，龐統的歷史命運在本版基線保留；不虛設第三條救龐統條件。

**入章。** 龐統把成都的位置一指：「地方很好，問題是人家還住在裡頭。」劉備沉默片刻，望向你：「進城之後，得讓人知道我們為何而來。」

**A｜進軍以後怎麼生活。**

- 保留地方糧籍，修復水利（`granary`）：不因換旗打散耕作，為新政提供基礎；記護民、仁政前置。
- 先穩住山口與武庫（`arsenal`）：整編交通與軍備，為漢中提供軍事前置。

**B｜把事情交給誰。**

- 讓新舊官吏共同交接（`handover`）：你不把所有公文收進自己案上，明定各署承辦；記交接，D-S2 第一準備。
- 由自己巡回統籌（`personal`）：迅速處理急務，取得當章收益；分工改命尚缺前置。

**七關。** 山口營 → 涪城外道 → 雒城前陣 → 險隘 → 成都糧路 → 城外精兵 → 護民入城。

**章末。** 劉備第一次邀你在真正的府衙吃飯，卻仍習慣把餅分開。空下的席位留給未能走到成都的龐統；眾人舉杯後，把他未完的地圖攤開。成果：城中開始復市。代價：部分工務延期，由新署接手。全通：你親手打開被封死的市門，第一批商販推車入城。

## S6｜漢中：這座山，我們一起拿下

ID `ch:shu.hanzhong`。R49–56。

**入章。** 黃忠試弓時，年輕人還在估山有多高。他放下弓，對你說：「我只管前頭那一箭。後頭的事，信你。」

**A｜山戰與後路。**

- 開漢中至荊州的接力聯絡（`corridor`）：預留關津、驛舟與援軍名額，放棄一份當章進攻獎勵；D-S1 第二準備。
- 集中精兵奪山（`assault`）：支援黃忠與法正的突破方案；軍事國策前置。

**B｜誰掌握糧道。**

- 建立可替換的糧運班底（`handover`）：讓蔣琬等人能在無主帥逐筆批示時運轉後勤；記交接，D-S2 第二準備。
- 由你親守前線倉道（`guard`）：強化當章前線供給；軍事國策前置。

**七關。** 山麓哨寨 → 弩台 → 定軍山隘 → 黃忠接戰 → 曹軍糧道 → 反攻精銳 → 漢水接應。

**章末。** 黃忠的箭旗在山頂展開，劉備與你並肩望向北方。成果：接應隊齊整抵達。代價：你部被迫退守山麓，由友軍完成主攻。全通：黃忠大笑著向你招手：「還能再上去一座！」

## S7｜荊州烽火：二哥，這次換我來接你

ID `ch:shu.jingzhou`。R57–64。明確分為「襄樊與荊州危局」及「其後東征／重修盟約」兩幕；後幕數年時間以章內字幕表示。

**入章。** 最初是捷報，接著是斷信，最後只有一個滿身泥水的傳令兵。帳內突然安靜。你展開早已備好的水路圖，手指落在麥城之外。

**A｜今夜是否出援。**

- 啟用盟約與接力水路（`rescue`）：需 S4.A=`pact`、S6.A=`corridor`，才能啟動完整 D-S1 挑戰。你把令旗往案上一按：「我知道他在哪裡。」無準備時可救散兵，明示尚不能救關羽。
- 集中保住西岸防線（`defend`）：穩定蜀軍退路，走常規命運，不把選項寫成懦弱。

**B｜戰後要追回什麼。**

- 以活人為先，重修盟約（`pact`）：若救援成功，關羽與你一起交出報復軍令，換俘虜與停戰；D-S1 完整收束。若未成功，演劉備東征、夷陵受挫後接受此約。
- 交下一代整訓國軍（`handover`）：記交接。成功救援後未締新約只算階段改寫；常規線則在夷陵之後保留部曲與經驗，不永久封死下一章。

**七關。** 漢水哨線 → 斷信驛 → 江陵外道 → 夜渡口 → 散兵接應 → 麥城外圍 → 關羽突圍。未啟用救援時，第六、七關改為「西岸撤離／退軍接應」，不讓玩家打到關羽身旁卻硬判沒救到。

**章末。** 改命成功：關羽踏上你的船，先確認追兵已遠，再朝你深深一揖。「這條命，往後與你同進退。」常規：關羽殞命，後續東征受挫，你護住歸來的部曲。救援只過 3–4 關：救到失散官兵，關羽尚未接上，給出明確缺口。完整救援門檻為第 5 關，詳改命線。全通：你與關羽並肩回身，替最後一艘船擋住追軍。

## S8｜北伐星火：丞相，剩下的路一起走

ID `ch:shu.northern`。R65–72。以北伐數次轉場收束至五丈原的夢中分歧，沒有把一輪戰役寫成單日攻到洛陽。

**入章。** 大帳還亮著。諸葛亮把最後一卷軍報移到燈下，發現你已坐在對面。你放下自己的那一份：「今夜，一人一半。」

**A｜把重擔接過來。**

- 啟用分工與輪值（`delegate`）：需 S5.B、S6.B 都是 `handover`，才能接起 D-S2。你帶來的是能運作的人與規程，沒有拿仙丹逼孔明睡覺。
- 集中資源決戰前線（`advance`）：追求常規軍事圓夢，北伐基線保留，軍事國策前置。

**B｜軍令留給明天。**

- 交接軍政，接受輪休（`handover`）：記交接；D-S2 最終承諾。孔明把一半批示交給蔣琬，又把另一半推給你：「既如此，別讓我明早來替你補。」
- 親领決勝先鋒（`vanguard`）：把自己的主結局定位在前線功業；沒有交接閉環則不宣告孔明長期得以卸重。

**七關。** 祁山外寨 → 隴道守備 → 前軍脫困 → 糧道攻防 → 渭水接應 → 司馬軍前鋒 → 五丈原對陣。第 5 關為 D-S2 決勝門檻；全通意味穩住本次攻勢，完整反攻成果放在改命終幕蒙太奇。

**章末。** 常規：孔明將未完成的圖交給眾人，你把它繼續攤平。改命：清晨他第一次沒有坐在案前；你在營外找到他，看他與孩子們爭論風箏為何飛不高。他見你來，笑著把線交過來。兩條改命都完成時，關羽站在不遠處等候下一次軍議；這是額外重聚鏡頭，不新增第七個改命主結局。

成果：前後軍依新令輪轉。代價：本次北伐受阻，補給與後送保留，缺少決勝門檻則不給成功結局。全通：晨鼓響起，孔明與你同時走出營帳，兩列將士舉旗相迎。

## 日常支線的方向

另列待後續擴寫的夥伴事件：張飛教新兵畫旗、趙雲替走失的小馬找主人、關羽替軍中孩子改木刀、諸葛亮修壞了三次才飛起的風箏、黃忠與年輕弓手較量。每人先製作一條三段鏈，以「初識的長處 → 相處的弱點 → 玩家成為可依靠的人」收束。本檔完成的是 8 章主線，這些日常鏈不是已完成劇本。
