# 逆天改命：讓準備變成那一刻的奇蹟

設計稿；六條改命是玩家可追求的完整故事，不是隨機的隱藏結局。**第一次玩就能完成**，不必先看人物死一次。南華老仙的夢痕只提供重玩提示，不供應免死貨幣。

## 共通規則

一條線分成「預告 → 兩項準備 → 決勝 → 守住成果 → 專屬終幕」。每項準備都是確定出現的主線選項，付出的是放棄另一選項的即時成長獎勵。所需戰役深度預先寫明，不再加一次成功率骰子。

啟動節點會顯示已完成的準備、缺少的準備，以及「本章需通過第幾關」。未備齊時允許救散兵、護家眷等普通選項，但名稱必須不同，不能顯示「救關羽」卻注定救不到。

**救到的人不會因後續普通戰敗被系統收回。** 達到救援關卡立即記錄階段成果；之後繼續打而落敗，只影響戰役原本的獎勵，不能刪掉已救出的角色。未完成後續承諾，保留存活與新增場景，但未取得完整改命主結局。

同國兩條線可以同局完成，沒有硬性互斥，也不需要指定抽卡陣容。門檻只讀故事準備、章內決定及該場最高已通關深度，戰力自然透過戰役驗收。不另設智力 90、某人五星等隱藏必備條件。

## D-W1｜留住奉孝：軍師，這回先算你自己

**遺憾與幻想。** 郭嘉病逝的敘事起點參照[《三國志》卷十四](https://zh.wikisource.org/wiki/三國志/卷14)；他獲救並參與赤壁後勤是本作原創改寫。核心爽點是讓總替別人算生路的人，被玩家替他算出一條。

**預告。** W2 勝後，他把你的糧道圖折得整整齊齊，卻不經意咳彎了腰。提示：「遠征不只要有去路，也要有病者能走的歸路。」

**準備一，W3.A。** 選建驛、醫隊。放棄另一選項的當章進攻向額外獎勵；實際文武功績不倒扣，不扣回已達官階。

**準備二，W3.B。** 請他後方統籌。對話：郭嘉：「我不去，前軍誰看？」你指向分工圖：「你在這裡，看得比任何人都遠。」他終於收回要拔營的令牌。

**決勝，W3 第四關。** 驛站接通，專人把郭嘉送回可休養的後營。閾值達成鏡頭：你把醫隊的平安回報帶進曹操帳內。曹操讀完，緊繃的肩終於放下：「這份功，我記你一生。」

**不足時。** 0–3 關只完成局部驛道，郭嘉未能及時轉送，走基線。結算說明「後營接應未通，第 4 關是轉送點」，不責怪玩家不夠在乎他。

**守住成果，W4。** 郭嘉不是必勝按鈕。他能與你一起看見船隊風險，仍需要你準備救生舟、親自接人並完成三關。赤壁大勢仍受挫，但你們保住隊伍，轉而規劃下一步。

**後續替換。** W4 加一段岸上接應；W5 加「這回你來出題，我來拆」；W6 退軍前他已替你畫好兩份退路。W7 以他與你共同帶出的一代謀士接續，不強行斷言活過所有後代。終幕回到屬於兩人的勝後片段，不與高平陵的年代同場。

**主結局〈奉孝仍在〉。**

戰報送到時，郭嘉正與你爭那條路到底該畫在河東還是河西。聽到捷報，他把棋子往案上一放，竟也愣了片刻。

你把當年沒喝成的酒推到他面前，這次他沒有先講計策，只笑著碰了你的杯：「原來活著看見，真比算到還痛快。」

窗外的新軍正要啟程。你們各取一支筆，把下一張圖攤開。

**夢醒。** 南華老仙：「連算無遺策的人，也沒算到有人肯替他走這一趟。」

## D-W2｜守住魏闕：今天起，誰也不能一句話奪走天下

**遺憾與幻想。** 取高平陵權力危局為改編舞台；公開調兵規程、受保障的朝議與玩家居中止兵都是夢中創作，不宣稱歷史本有這條成熟制度。

**預告，W7。** 兩份不同印信的軍令同時送到。提示：「能查清一封假令，還需要讓後來的人有權查。」

**準備。** 公開軍籍調兵規程，讓多署及新將領實際練習共同覆核。代價是錯過個人親掌精兵的即時獎勵，沒有額外貨幣門檻。

**決勝，W8.A。** 你帶著不同時期培養的副將守住太倉、武庫、洛水通路。司馬懿的使者問：「你要與誰為敵？」你將軍令展開：「誰越過它，我就攔誰。」

通過第五關後，皇室與各方官員抵達可正常議事的場所。你有軍事能力保護程序，並有先前獲認可的規程作支點，才能逼迫双方回到議事；不是靠一封信勸服所有人。

**不足時。** 護送部分人出城，朝議未成立，原權力更迭繼續。前期培養的人與你一同撤回，轉入常規公器或個人結局。

**守住成果，W8.B。** 公開交接，讓自己也受限制。選親掌兵權則保留止亂階段紀錄，但不授予「天下再無私門」式成果。

**主結局〈魏闕長明〉。**

早朝鐘聲響起，百官依次進殿。那名當年連旗號都分不清的副將，如今站在階下，攔住一份印信不全的軍令。

他抬頭看你。你把自己的佩劍解下，交給他查驗。

大門在晨光中打開。這一次，連你也不能獨自決定門後的天下，而你比任何一次得勝都笑得暢快。

**夢醒。**「原來你最高的一步，是把自己的手也放下來。」

## D-S1｜麥城回馬：二哥，援軍到了

**遺憾與幻想。** 荊州衝突的多方利益以[《三國志》卷五十四](https://zh.wikisource.org/zh/三國志/卷54)為參照；跨國救援協議、接應成功與其後和解皆為原創。救援只先保住關羽，不自動保住整個荊州。

**預告，S4。** 關羽看著江水說，軍使一斷，再好的盟約也趕不上刀快。你與魯肅把船與旗號寫入紙上。提示：「留得下的通道，有一天會比多得的一座營寨更重要。」

**兩項準備。** S4 定具體互援通航；S6 備荊州聯絡與援軍名額。沒有隨機刷密信的最後一塊拼圖。

**決勝，S7.A。** 前四關打通聯絡，第五關取得夜渡接應點。鏡頭切至關羽被追兵逼在河道旁，你的船燈依約亮起。他先認出旗號，隨後聽見你喊：「二哥！別看後面，看這裡！」

關羽跳上船，你用槍杆撑開逼近的敵舟。第五關當下即記「救出」，第六、七關是斷後與全隊撤出，不是拖到最後才抽人物能否活命。

**不足時。** 通過 3–4 關可救出具名散兵，仍未接到關羽；0–2 關保住前線驛站。都告知缺口，不暗示只差一點好感。

**守住成果，S7.B。** 關羽願意為將士歸家與新盟約出面，劉備選擇先接兄弟回來。故事直接改寫後續報復鏈：不發生該線原本的夷陵復仇，張飛也不進入該套悲劇橋段。這是本作分歧，不是「救一人必然救所有人」的史實推論。

**後續。** S8 關羽可參與軍議；劉備、張飛以回憶／家宴片段回應玩家功勞。若沒有完成和約，三人仍可先重聚，但局勢未穩，不給正式改命結局。未以玩家準備支持的長壽，不向後無限延伸。

**主結局〈桃園再聚〉。**

張飛一把掀開酒壇封泥，嚷著誰都不許少喝。關羽正要板起臉，被劉備先按回座位。桌上多擺了一只碗，位置就在三人之間。

你還站在門口，劉備已向你招手：「這席，等的就是你。」

落花飄進酒裡。你曾在別人的故事裡見過這場相逢，如今終於能親自坐下，聽他們把明天說得很長。

**夢醒。**「有些酒，你等了不只一場夢。」

## D-S2｜五丈原續燈：丞相，這次換我們撐住

**遺憾與幻想。** 北伐與諸葛亮生平以[《三國志》卷三十五](https://zh.wikisource.org/wiki/三國志/卷35)為起點。續燈是文學意象，成功原因是分工、補給與戰力，不靠法術治病。存活及復興都是明示的夢中改寫。

**預告，S5。** 孔明把連縣署小事都批完，你問還有哪些可交出去。他指向幾份尚無人接得住的文書。提示：「想讓他歇下來，先讓那些事真的有人會做。」

**準備。** 入蜀培養接班官署；漢中建立可替代的糧運班底。兩者分在不同章，讓玩家看見幾年準備終於接起來。

**決勝，S8。** 你主張輪值，帶著能獨立執行任務的人出征。第五關穩住補給接應，副將按既定方案救回前軍，不再整夜等待孔明一人批示。

對話：你把批示簿按下：「您教我們這麼久，也該讓我們真的會一回。」孔明看著營外完成換防的旗，終於把筆交到你手上。

**不足時。** 本次攻勢與交接未能完全接上，孔明仍依基線病逝；你接續他的工作，可達〈薪火不息〉。不讓「尊敬他」與「成功救他」混成同一個旗標。

**守住成果。** B 選公開交接與輪休，第五關成果成立後才播放他接受休養的回應。成功後孔明真的能留在故事裡；後續勝利通過多年准備蒙太奇呈現，不用「下一年仍然累死」反悔。

**主結局〈漢室再曉〉。**

鏡頭依次越過重修的糧道、接棒的新軍與數次並肩完成的戰役。多年後，漢旗重新升上舊都城頭。百姓的歡呼像潮水，從城門一路推到階前。

你回身去找那個總在最後收拾地圖的人，卻見孔明早已站在陽光下。他沒有先談下一步，只把羽扇收起，朝你鄭重一揖。

「這一次，亮看見了。」

你伸手扶住他。遠方晨鼓響起，你們一起向前。

**與 D-S1 同成。** 加一鏡關羽護送新軍入城；未救關羽則用趙雲的傳旗回憶與下一代將領入城，不讓已亡者無標記復活。終幕是跨年蒙太奇，具體歷史人物同場均受本線存活／時間標記限制。

**夢醒。**「天上的星沒多一顆。只是這回，撐住它的人多了。」

## D-U1｜小霸王歸航：伯符，明天還等著你

**遺憾與幻想。** 孫策受襲與身後交接以[《三國志》卷四十六](https://zh.wikisource.org/wiki/三國志/卷46)為參照；情報部署救援、兄弟共同經營是原創。

**預告，U2。** 地方密報夾著幾次異常的問路與買馬，孫策卻只關心下一座城。你把紙按住：「這幾件，也許是一件。」

**準備。** 建情報網；獵前啟動交叉護衛與回報路。孫策不是被強制關起來，他同意受信號約束，仍保持主動與膽氣。

**決勝，U3 第五關。** 你們從兩側趕到，孫策本已做好殊死一搏，卻看見你扔來第二支槍。「有架不叫人，可不算兄弟！」兩人背靠背衝出伏擊。

**不足時。** 外圍捕獲刺客但未接上主帥，依基線傷逝。指出缺的是第五關接應，不靠醫生突然忘記治療。

**守住成果。** B 選兄弟分工。孫策親自將政務與部分軍令交給孫權，在群臣前給弟弟完整的授權；讓救回來的哥哥促成弟弟成長。

**後續替換。** U4 孫策負責接應、孫權定策、周瑜統戰；U5 兄弟對先北進或先固江防有一次爭論；U8 若出場則只作旁證，不壓過孫權的認錯與選擇。跨至晚年需字幕明示夢中延壽，不把活過遇刺直接當幾十年不老的保證。

**主結局〈江東雙璧〉。**

孫策把戰船模型擺上桌，說下一次要造得更大。孫權把他畫得過大的帆改小，兩人差點又吵起來。你與周瑜坐在一旁，誰也不勸。

窗外，真正的新船正緩緩下水。孫策搶先走到門口，這一次卻沒有獨自跨出去。他回身伸手，等弟弟，也等你。

「走。咱們一起看。」

**夢醒。**「原來意氣風發，也可以有人同行到後面。」

## D-U2｜二宮止爭：江東的燈，不該照著自己人的刀

**遺憾與幻想。** 儲位紛爭及人物關係以[《三國志》卷五十九](https://zh.wikisource.org/wiki/三國志/卷59)與[陸遜傳](https://zh.wikisource.org/wiki/陸遜傳)為參照；受保障的呈議、避免清算與繼承安排皆為夢中創作。

**預告，U7。** 年輕將領問同一份任命為何有兩個版本，張昭／後繼官署提供制度討論，不讓已離世人物無字幕在晚期返場。提示：「讓人說得出來，還要讓他說完之後回得去。」

**準備。** 把可核對軍政文書、反對意見入口及輔政次序真正訂下，提前一章運作。核心證據是既有詔令、當事人與外鎮回函，沒有臨時冒出的万能密詔。

**決勝，U8 第五關。** 你護住官署、文書與證人，讓陸遜的完整奏議在公開場合呈上。陸遜並非拒死等你，而是與你共同備妥替代安排。

你對孫權說：「當年大家信您，才敢把背後交出來。今日請您也信一次，把這些話聽完。」軍事上已止住私兵攔截，政治上有可接受的繼承方案，孫權才有條件退回公開議事。

**不足時。** 成功撤出部分家眷，但朝議遭阻，原局勢繼續；玩家仍可收束〈千帆歸港〉或〈滿堂英傑〉，不是全部準備歸零。

**守住成果。** B 選公布繼承與輔政安排。孫權撤回錯誤處置，確認孫和儲位、將孫霸移出爭儲權力位置並保留其性命，陸遜獲公開平反。此具體安排為本作虛構解法；並非泛泛「大家和好了」。

**主結局〈江月長明〉。**

陸遜跨出宮門，第一次發現門外等的不是押送他的兵，而是一排提著燈的舊部。你走上前，替他接過厚厚一卷奏疏。

多年後，新主即位的鐘聲傳過江面。群臣依照早已公布的次序入朝，港口照常開市，沒有誰連夜收拾行李逃走。

你靠在欄邊，看月亮升起。這片江山終於肯讓替它打仗的人，也有一個安穩的明天。

**夢醒。**「最難得的捷報，有時一個戰死的名字也沒有。」

## 提示文案與重玩公平
