# 主線對話第一批接入 · 2026-09-14

這是金幣改版後的實作紀錄，與 IMPLEMENTATION.md 的舊非 UI 原型分開。本批在工作分支完成，尚未提交或推回 Main。

## 內容與流程

共通黃巾、魏線現有虎牢／官渡／河北三章、蜀線八章，共 12 章、24 個主線抉擇節點。新局依序播放入章開場、第 2／6 回合抉擇、對應回應、戰役里程碑與章末收束，再進章間整備。

主線不另消耗行動，佔該回合人物事件的位置；普通委託與實得獎勵先播放。第 6 回合的戰後承諾延後回收；救援不足使用失敗／部分完成的收束。主線選項目前記劇情狀態，不另給一套養成獎勵，既有固定行動與委託薪水照常。

所有主線編成逐句腳本：speaker 為 null 時是無頭像的系統敘述，角色開口才顯示頭像。維持小對話框、點畫面繼續、黑描邊、姓名黃色；選項在上方獨立展開，下面保留上一句。人物從左右入場，換句不重複入場。

河北第 4 關郭嘉轉送、荊州第 5 關關羽救援、北伐第 5 關接班成果立即保存，之後敗退不撤銷。蜀線雙成果可共存，終章後選本輪紀念結局。

本輪存檔容器改為 v4。v3 金幣存檔保留進度並停用新增主線，避免倒灌錯過的選擇。讀檔從尚未完成片段的首句重播，已提交選項不再提交。

## 試看入口

以上入口都不讀寫玩家本輪或天命存檔。一般首頁的新局則啟用主線。
