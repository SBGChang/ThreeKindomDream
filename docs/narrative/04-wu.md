# 吳國篇：把江東的旗，一起帶到明天

設計稿；8 章、64 回合。江東不是站在旁邊等魏蜀打完：玩家參與渡江開業、群英接力、水陸聯戰與繼承危局。主調是「這份家業，大家一起打下來，也要一起守住」。

## U1｜虎牢先登：江東的人，走在前頭

ID `ch:wu.hulao`。R9–16。

**入章。** 盟軍尚在推辭誰出前鋒，孫堅已把頭盔扣上。你追到營門，問還缺什麼。他回頭：「缺個不把話說在脚前頭的人。來不來？」

**A｜前鋒缺糧。**

- 護船接通糧道（`supply`）：你帶船隊穿過被切斷的河段。黃蓋把糧袋扛上岸：「這下，罵人的力氣也有了。」
- 直取前營解圍（`charge`）：你和前鋒同時夾擊，替友軍打開缺口；軍事前置。

**B｜城外傷兵。**

- 收容沿途百姓與傷卒（`shelter`）：孫堅將你留下的護送旗插在營門；記護民。
- 讓新隊長掌管前鋒接防（`handover`）：你與黃蓋演示一次，就讓年輕人自己做；記交接。

**七關。** 河岸哨寨 → 運糧路 → 聯軍缺口 → 西涼前鋒 → 關下營 → 華雄部 → 洛陽外圍。與魏蜀不同，吳篇重點是孫堅軍向前推進，不共用呂布末關。

**章末。** 你在焦黑的街道上找到一戶未走的老人，孫堅下令先送人出城。成果：前鋒與護送隊同時返營。代價：黄蓋帶援軍接回你。全通：孫堅把一面備旗交給你：「下次，你也能帶一路。」

## U2｜小霸王渡江：拿回我們的起點

ID `ch:wu.jiangdong`。R17–24。章首明示孫堅已逝，孫策集結舊部、借兵渡江。

**入章。** 孫策站在還沒塞滿人的船上，指著江對岸：「等著。總有一天，這些船坐不下咱們的人。」周瑜笑他先別把船喊翻，你替兩人把纜繩解開。

**A｜剛落腳的營地。**

- 建哨站、查訪地方消息（`scouts`）：把散亂消息交叉核對，結成能回報到人的情報網；D-U1 第一準備。
- 集兵搶城（`assault`）：趁對手未穩向內陸推進；軍事前置。

**B｜打下來以後。**

- 修碼頭，保住農商往來（`harbor`）：你把徵用船隻逐一登記歸還；記護民，商路國策前置。
- 教新將領分區駐防（`handover`）：孫策問你敢不敢讓新人守一座城，你答：「敢，但先把接應交代清楚。」記交接。

**七關。** 渡江搶灘 → 河口壁壘 → 牛渚營 → 山道 → 地方聯軍 → 曲阿外圍 → 太史慈交鋒。末關為交鋒後相知，不擊殺可用名士。

**章末。** 孫策從馬上跳下，把你與周瑜一把攬住：「看見沒有！真讓我們過來了！」成果：新城開始卸糧。代價：你部休整，盟軍補齊接防。全通：太史慈應約歸來，身後還帶著一隊人。

## U3｜獵場驚雷：別讓這一箭射中明天

ID `ch:wu.hunt`。R25–32。

**入章。** 孫策嫌親衛走得慢，翻身便要出營。你把韁繩按住，遞上最近幾封互相呼應的密報。他挑眉：「連出去透口氣，你也備了陣？」

**A｜狩獵前夕。**

- 部署交叉護衛與回報路（`escort`）：有 U2.A=`scouts` 才能鎖定伏擊範圍；D-U1 第二準備。孫策答應以旗號保持聯絡，仍親自出行誘敵現形。
- 先處理城內軍務（`city`）：保住本營與家眷，狩獵依基線發生；不給「我早知道但故意不救」的先知台詞。

**B｜此後由誰帶江東。**

- 把軍政分工交給孫權與群臣（`handover`）：記交接；若救援成功，孫策親自替弟弟立威，是 D-U1 完整收束。
- 請主帥繼續集權領軍（`personal`）：短期整軍，若已救孫策只計救援成功，不給兄弟並肩終局。

**七關。** 林外哨點 → 斷訊小徑 → 刺客前伏 → 山澗 → 孫策接應 → 回營追襲 → 捕獲伏擊頭目。未啟動救援方案時，改為城外清剿七關，末三關為「護眷道／糧倉／城門」，避免虛假的救援成功。

**章末。** 常規：孫策傷重辭世，孫權接印，手指尚在發抖。改命：你架著孫策回營，孫權幾乎撞翻案桌。孫策還想逞強，被你和周瑜一起按回座位：「坐好。這次聽我們的。」成果：救援接應完成。代價：路線受阻，改命按實際深度結算。全通：密報與首謀一併帶回，孫策親自向護衛道謝。

## U4｜赤壁同心：讓這把火照亮江東

ID `ch:wu.chibi`。R33–40。

**入章。** 戰與降的議論塞滿大帳。孫權沒有立刻說話，先看向周瑜，又看向你。你把已整備好的船隊名冊呈上：「將士在，糧船在。就等一聲令下。」

**A｜聯軍的約定。**

- 明訂互援與戰後通航（`pact`）：讓孫劉雙方的救援與利益都有可執行安排；商路／聯盟前置。
- 集中打造決勝火船（`fireships`）：支援周瑜與黃蓋的主攻；軍事前置。

**B｜決戰接力。**

- 親領落水救援（`shelter`）：你跟在火船後方接人，不讓勝利只剩一片火海；記護民。
- 讓各隊將領分段接令（`handover`）：周瑜的總令由多名將領銜接，而非誰都等他的旗；記交接。

**七關。** 江口哨舟 → 水寨 → 黃蓋航路 → 曹軍戰船 → 火線突入 → 岸營 → 救援返航。

**章末。** 周瑜聽著遠處的鼓聲，用手指在船沿輕敲兩下：「最後一拍，到了。」成果：救援舟在夜色中逐一回來。代價：你的隊伍由盟友接應，主攻成果仍成立。全通：江岸所有守軍舉起火把，照你最後一程。孫策存活時在接應岸與孫權並肩接旗，不奪周瑜本章主角位置。

## U5｜江上雙鋒：既要向北，也要守住上游

ID `ch:wu.jinghuai`。R41–48。時間字幕分別交代合肥受挫、荊州局勢變化；兩線不假裝同日。

**入章。** 地圖一端是合肥，一端是荊州。魯肅留下的盟約還在，新的軍報卻已催促取捨。呂蒙把書放下：「多讀幾卷，才知道這一仗不能只看眼前。」

**A｜先保住什麼。**

- 保留對岸使者與通航窗口（`pact`）：即使局勢惡化，也留能交換消息與俘虜的管道；商路前置，不單憑此選項避免歷史衝突。
- 準備水陸合擊（`strike`）：保障上游軍事通道；軍事前置。

**B｜城池接管。**

- 維持居民生計與歸鄉路（`shelter`）：你命船隊護送家眷、登記待交換俘虜；記護民。
- 新舊守將共同交接（`handover`）：記交接；呂蒙把城防圖交到下一個人的手裡。

**七關。** 合肥外道 → 逍遙津撤離 → 江防換軍 → 荊州哨舟 → 上游碼頭 → 南郡外圍 → 城中接管。前兩關後用字幕跳轉至荊州戰事，兵糧數值仍依同一場章末戰役處理，屬抽象驗收。

**章末。** 基線荊州易手、關羽殞命的消息傳來。孫權沒有設盛宴：「贏來的地方，得守得住。」成果：你讓新占城池維持市集。代價：交接混亂，由後援接續。全通：此前互為敵人的守卒一起守住糧倉。此章不暗藏第三條救關羽路線；吳方救關羽可作後續擴充。

## U6｜夷陵待風：年輕的都督，等你一句話

ID `ch:wu.yiling`。R49–56。

**入章。** 老將們不服陸遜，帐外天天有人請戰。陸遜將地圖递給你：「你也覺得我只會等？」你看過他標出的每一條糧路：「你在等的，我替你守。」

**A｜全軍躁動。**

- 協助陸遜維持統一節奏（`trust`）：你按明確輪換表輪防，不讓任何一部提前暴露部署；軍事前置。
- 加固後方、接出沿線居民（`shelter`）：守住容許長期相持的根基；記護民。

**B｜終於能出擊。**

- 交分隊將領按號並進（`handover`）：記交接。陸遜親自確認每人都知道何時停、何時進。
- 親率一翼突擊（`assault`）：軍事前置。你與陸遜互換出擊旗令。

**七關。** 山道前哨 → 蜀軍壁壘 → 溪谷 → 火線缺口 → 連營後路 → 撤軍追擊 → 止追界線。末關是阻止敵方殘部反擊並收束追兵，不擊殺劉備。

**章末。** 軍議再開，昨日質疑陸遜的將領首先起身行禮。成果：你按時止追，留住可談判的局面。代價：本隊陷入苦戰，陸遜派預備隊接回。全通：你把最後一道止追令送到，漫山鼓聲依次停下。

## U7｜石亭揚帆：我們已能把勝利接下去

ID `ch:wu.shiting`。R57–64。戰後政務場景明示時間經過，承接儲位與朝議規程鋪墊。

**入章。** 新一代水軍把戰船推到江心。陸遜問你這支軍隊與當年有何不同。你望著一排排自己帶過的人：「這次，不必只有我們幾個知道怎麼贏。」

**A｜整軍之外的一份奏議。**

- 確立軍政交接與議事程序（`charter`）：要求關鍵任免留下可核對的文書、反對意見有呈報入口；D-U2 第一準備。
- 開拓港市與轉運（`harbor`）：讓勝利保護的商路真正運作；商路國策前置，記護民。

**B｜接班人的名字。**

- 建立共同輔政與明定儲位秩序（`handover`）：記交接，D-U2 第二準備；不以單純孫登好感取代制度。
- 優先授勳前線將領（`honor`）：軍事國策前置，維持現有繼承基線。

**七關。** 邊道斥候 → 偽降誘敵 → 石亭外寨 → 魏軍側營 → 夾擊缺口 → 曹休退路 → 援軍阻截。

**章末。** 陸遜把捷報交給年輕副將去念，你與他站到席旁。成果：兩代將領同席慶功。代價：本隊退出追擊，在後方護住俘虜與傷兵。全通：你當年教過的新將領，完成了最後一次合圍。

## U8｜二宮風暴：江東的明天，不拿來內耗

ID `ch:wu.succession`。R65–72。孫登去世後的繼承紛爭明示為多年後，不把他寫成仍在場調停。

**入章。** 邊關送來的捷報無人打開，案上盡是互相指控的文書。陸遜的奏疏被壓在最下方。你將它抽出，抖平：「這封，今天一定要讓主公看見。」

**A｜封閉的朝議。**

- 依既定程序保護呈議與證人（`hearing`）：需 U7.A=`charter`、U7.B=`handover` 才能啟動 D-U2。目標是讓孫權聽見完整陳述，阻止黨爭借軍隊清算。
- 先護送被牽連的家眷（`shelter`）：記護民；普通局面下仍能救下具名家庭，不是毫無成果的失敗按鈕。

**B｜從明天開始。**

- 公布繼承與輔政安排（`handover`）：記交接，D-U2 完整收束；孫權親自撤回違反程序的處分。
- 自請外任，守住江防（`guard`）：軍事國策承諾，已護送成功者保留階段成果。

**七關。** 都城水門 → 文書護送 → 私兵攔路 → 證人接應 → 朝議通道 → 武庫換防 → 諸營止兵。不是與孫權決鬥，而是讓朝廷能恢復正常決策。

**章末。** 常規：朝局風波仍留遺憾，你把保住的人與事帶到自己的結局。改命：孫權讀完奏疏，起身走下座位，向陸遜與群臣承認處置失當；隨後公開新令。孫策若在世，只說「這回，你自己做得很好」，不替孫權回答。

成果：證人、文書與外鎮回函齊備。代價：護送受阻，朝議未能及時展開，仍結算本隊成果。全通：江上停泊的戰船依次熄下戰燈，換成歸航燈。

## 日常支線方向

周瑜聽出你敲錯的鼓點；魯肅替兩營分飯分得一樣多，自己那碗卻最少；呂蒙讀書不懂便去追問，而你開始答不出來；甘寧替夜襲船上的新兵解開打錯的繩結；孫策和孫權搶著修一艘童年小船。上述為後續三段人物鏈的選題，本文交付的是主線劇本。
