## 原型曾完成的流程

正常入夢，完成黃巾共通章後選「蜀・劉備」。舊魏局可繼續，開始新局才能選蜀。蜀線包含共通 8 回合、蜀篇 64 回合，共 72 回合；魏線仍為 32 回合。

- 蜀八章：虎牢、徐州、長坂、赤壁、入蜀、漢中、荊州、北伐。每章有開場、第 2／6 回合各二選一、七關戰役與章末收束。
- 六位可養成名士：劉備、關羽、張飛、趙雲、諸葛亮、蔣琬；各一則同行事件。其餘人物暫時只有劇情出場。
- 新增主線手記，記錄已讀演出與 16 次選擇；保留主線前的固定養成與委託，該回合不再抽隨機人物事件。
- 荊州：赤壁盟約 → 漢中援路 → 本章救援 → 實際通過第五關，救出關羽。再有本章重立盟約承諾，可得「桃園再聚」。
- 北伐：入蜀交接 → 漢中糧運接班 → 本章輪值 → 實際通過第五關，穩住孔明休養。再有本章正式交接承諾，可得「漢室再曉」。
- 救援一旦完成，即使後續敗退也保留；部分完成有專用收束，不冒充完整改命。兩條都完成時由玩家選本次入冊的主結局，結算倍率只取一次。
- 六位蜀將尚無獨立人物立繪，以姓名將印呈現，後續需要補美術。
