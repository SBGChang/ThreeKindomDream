## 一、先鎖住長度與數值預算

**共同序章＋國線八章。IF 可以換掉後半段歷史，但不能多打一章。**

| 項目 | 所有可走路徑共同限制 |
|---|---|
| 養成 | 序章 8 回合＋八章各 8 回合＝72 回合 |
| 戰役 | 序章 1 場＋國線 8 場＝9 場；不插入額外短戰役 |
| 關卡 | 每場仍為 7 關，最多 63 關挑戰機會；失敗／撤退不保證打滿 |
| 決策 | 每章第 2、6 回合各一次 A／B 決策，共 18 個決策節點；不新增 P1／P2 |
| 接線 | 第 n 章只能接第 n＋1 章；所有國線終幕都在第 8 章後 |
| 獎勵 | 同國、同章位、同關序沿用同一獎勵預算；不加 IF 額外經驗、碎片、功績或補給 |
| 消耗 | 同章共用原有兵力、補給與技能使用規則；蒙太奇不能回滿再打一場 |
| 難度 | 以章位與關序定基準；更換敵人、目標與演出，不因故事勝得更大就無限制提高數值 |

章節「定義」可以增加，但單次遊玩的章數不變。西域開拓、宛洛決戰、海陸通商都放在第八章七關之內。人物解鎖是跨夢資格，不在本夢送額外養成資源。

這能固定平衡的比較基準，**不代表替換戰役已經通過平衡測試**。未來仍須比較技能相剋、兵種組合、每關損耗與各章達標率。

## 二、判定語言與人物狀態

- 「通過第 k 關」指本章正式戰役已連續通過前 k 關；「全勝」指第 7 關通過。失敗、撤退或未達門檻都走未成立出口。
- A、B 是兩個既有決策節點，每個各有兩個選項。選項在戰役開始前確定；不於關卡中增加一個付費或免費養成決策。
- 故事準備只改變任務、成果資格與後續劇本；本案不額外發放戰鬥增益。原有選項收益須在同章既有預算內重新分配。
- 章節入口依本夢國勢固定；同行修正再覆蓋人物演出。不能靠換出戰者重選版本；「在隊」包含玩伴與上司。
- 已解鎖但本夢未入隊，仍重新經歷 NPC 原線與救援檢定。入隊才有同行版；不能同場存在友方與敵方的同一人。
- 救援達標當下永久解鎖並保存本夢存活，後段敗北不撤銷。同行任務失敗不殺死隊友，只損失據點、接應成果或制度目標。
- 當夢獲救不立即加入可操作隊伍；從下一夢起有機率抽到。所有救援首輪可挑戰，不要求先有本人。
- 失敗接回既有章名時保留已發生的歷史改變；不能讓已收復的地區、已存活的人、已建立的盟約無說明消失。
- 章間可以跨年，須明示年代。獲救 NPC 後世以交接、書信或回憶出場；已入隊者依夢境同行年歲設定，不重演其歷史死亡。
- 所有國線結局須走到第八章；中途取得的「江淮立足」等只是成果，不能提早當完整結局。多人物成果皆保存，總結算只做一次。

### 3.2 赤壁的分歧必須是「打贏戰略」，不能只是撤得漂亮

W4.A：`boats` 分舟、防火與保留機動艦／`assault` 集中強攻。
W4.B：`counterfire` 反制火攻後反攻／`evacuate` 優先全軍撤離。

**A=boats、B=counterfire、全勝**三者齊備才記錄赤壁戰略勝利。撤離路即使七關全過，也只代表保全軍隊，後續仍是漢中。戰前明示兩種目標。

反攻七關：病營安置 → 分舟警戒 → 火船截斷 → 江面反攻 → 烏林奪岸 → 聯軍退路 → 江防接管。撤離版對應同七個關序，後四關改成護運與撤渡，不另打一場。

W5 不因赤壁勝利而消失：曹操先穩定關中與西進補給，防止進蜀後腹背受敵。W5 勝負影響本章成果；是否進成都只讀 W4 戰略結果。

### 3.3 W6 成都：劉備投靠劉璋的新歷史

劉備在赤壁失去立足機會，率餘部入蜀依附劉璋。劉璋仍是成都之主，劉備以客軍協防，兩人有互需也有猜忌；不能照搬「劉備已據蜀」的漢中劇本。

- A：`register` 先公布降附與安民約／`siege` 先封鎖軍事要道。
- B：`divide` 向劉璋與客軍分別議降／`press` 合軍攻城。
- 七關：劍門前哨 → 糧道護送 → 涪城外圍 → 客軍防線 → 成都北門 → 城內止亂 → 劉璋議降。
- 兩種部署皆有可能全勝；不多加隱藏的「正確選項」。A／B 改變談判台詞與結局責任，全勝才使蜀地局勢足以交接。
- 全勝：劉璋交出軍政，劉備及其部屬的安置在本章落定，W7 轉北疆。若劉備在隊，客軍由其舊部推舉的蜀中守將指揮，劉備改為調停者，不出現敵方劉備。
- 未全勝：成都未被穩定接管，曹軍止於既有據點，章末交代西征受阻、後來權力移交；W7 新朝討論如何約束軍政承諾。赤壁勝利仍成立。

### 3.4 W7 北拒匈奴：勝後能不能守住邊疆

成都已定，北疆部落聯軍趁軍隊輪調侵擾。戰爭主題從擴張改成守土、互市與邊地秩序；不把所有族群寫成敵軍。

- A：`charter` 軍民共用邊防簿／`raid` 以機動出擊優先。
- B：`handover` 分區交接軍權／`retain` 中軍統一收權。
- 七關：雁門警報 → 村鎮撤護 → 糧道守備 → 邊騎迂迴 → 敵軍主營 → 邊塞復防 → 互市通道保全。
- 全勝→W8 治世之能臣；未全勝→W8 高平陵。不是額外補一章新朝，而由章間字幕交代多年軍權集中、權臣爭衡。
- 失敗版高平陵仍承認成都已定，政變爭奪的是這個更大國家的權力。A/B 的制度準備沿用到後章，不因沒走新朝而讓魏闕線無法成立。

### 3.5 W8 兩種終局

**高平陵**：A=`audit` 公示軍政名冊／`conceal` 秘密控制要道；B=`handover` 依法交接／`centralize` 集中權力。前章 A=charter、B=handover，且本章 A=audit、通過第 5 關，成立「朝議得保」；再以 B=handover 並全勝，完成〈魏闕長明〉。未達完整條件仍於本章結束，區分保全人物、止住政變與制度未成。

新朝版 W7 的 A/B 同樣是公開章程／軍令優先、制度交接／個人收權，因此兩種 W7 入口有等價制度準備。曹操在隊時以主動交政取代死亡，不可播放其病逝台詞。

**治世之能臣**：曹操在本分支仍為漢相，沒有先稱帝再強行改回丞相。A=`charter` 公開賦役與軍糧／`mobilize` 集中資源開拓；B=`handover` 地方與中樞分工／`retain` 丞相統攬。

七關：糧道護運 → 屯田安置 → 地方止亂 → 議政護送 → 邊軍交接 → 河西通道 → 西域開拓。最後一關表現保全使團、打通商路與設置補給；不另加一次養成或第八關能力骰。

全勝且本章公開章程＋交接，結局〈治世之能臣〉：曹操留下能運轉的治理體系，西域往來成立。全勝但集中權力為〈盛世待續〉，有拓土而交接未竟；未全勝則〈守成有憾〉，依已通過關卡交代國內治理成果與西域未成，當場收束。

### 4.2 S5 龐統準備整合，撤回額外 P1／P2

A：`survey` 實地勘路並設回報／`arsenal` 優先接管軍械。
B：`handover` 前軍接應與官署交接／`personal` 主帥親掌各事。

七關：入境接糧 → 山道斥候 → 前軍分隊 → 伏兵警訊 → 落鳳接應 → 雒城外圍 → 成都交接。

A=survey、B=handover 且通過第 5 關，即救出龐統；第五關後再輸，不取消救援。B 同時是諸葛亮後期交接的伏筆，讓三條蜀國人物線可以同局完成，但不自動替其他救援過關。

同行版：龐統與玩家共同勘路，危機變成前軍誤入伏道；第五關是接回前軍。龐統不再自己中箭。若同行任務失敗，他仍活著，可參與雙謀版漢中，但不給前軍接應成果。

### 4.3 S6 雙謀漢中：活下來的人必須改變後面的事

龐統負責拆解敵方布防，諸葛亮負責糧運與指揮交接，法正提供情報核實；不是多一段「幸好你活著」後照舊。

普通與雙謀版共用 A：`corridor` 留通往荊州的接援線／`concentrate` 全力投入漢中；B：`handover` 分層交令／`personal` 主帥總攬。

雙謀七關：山口偵察 → 糧道接力 → 雙軍誘敵 → 定軍山外圍 → 山地合擊 → 援軍截斷 → 漢中接管。普通版沿基礎七關，難度與收益按關序對齊。

**S4.A=pact、S6.A=corridor、S6 全勝**→荊襄會盟。少一項→荊州危局。龐統生還影響本章劇情與後續軍議，卻不是能否保荊州的必備角色門票。

### 4.4 S7 荊州危局：救到人不等於救到整個戰略

A：`rescue` 接回關羽與守軍／`hold` 優先守住後方據點。
B：`pact` 延續吳蜀互不越界承諾／`revenge` 集中復仇動員。

S4.A=pact、S6.A=corridor、S7.A=rescue 且通過第 5 關，即救援成立，永久解鎖關羽。劇情仍是敗走麥城，但關羽活著離開：「若有來世，願能更早與你相識。」此版本沒有足夠前期戰略基礎保住整個荊州，七關全勝也只是撤軍與接應成功，S8 仍為北伐。

同行版改為關羽與玩家共同接援、掩護荊州軍，不播放尋找或死亡演出；勝負決定部隊與據點，不能用關羽在隊直接跳去兩路北伐。

七關：江岸預警 → 守軍集結 → 撤路奪回 → 追兵攔截 → 麥城接應／同行接援 → 百姓渡江 → 殿後歸營。

### 4.5 S7 荊襄會盟：不再發生同一場麥城敗局

漢中取得決定性成果，接援線尚在，吳蜀有談判籌碼。曹軍試圖挑動雙方衝突，關羽面臨的是前線冒進與盟軍誤判，不是預定要再敗走麥城。

A/B 與危局版同義，使讀者可預期人物條件。七關：邊界止衝 → 信使護送 → 樊城牽制 → 江岸防突 → 荊州接援 → 盟軍解圍 → 荊襄守約。

- 前置已在入章確認；A=rescue 且第 5 關成功取得「關羽接援」，與救援等價開放角色。台詞改為「今日並肩，竟像早已相識。」手記記接援，不能假寫麥城撤退。
- **A=rescue、B=pact 且全勝**→S8 兩路北伐。荊州保全，孫劉同盟續存；劉備沒有因關羽之死發動夷陵的因果。
- 其他→S8 北伐。依失敗點記錄盟約未固、戰線收縮；若已接回關羽就保留其存活，不能回放祭關羽。

### 4.6 S8 兩種終局

兩版 A：`delegate` 分工與休養／`exhaust` 集中由主帥處置；B：`handover` 培養新軍並交令／`retain` 暫留主帥統一指揮。

**北伐版**：祁山前哨 → 糧道輪替 → 山路守援 → 指揮接替 → 五丈原續燈 → 前軍回接 → 祁山突破。S5.B=handover、S6.B=handover、S8.A=delegate、通過第 5 關可救諸葛亮。全勝＋本章交接收束〈續燈有後〉；未滿完整條件依存活與戰果收束〈北伐未竟〉，不添加下一次北伐。

**兩路北伐版**：蜀道出師 → 荊襄策應 → 糧運會合 → 兩軍分掌 → 軍師輪休 → 宛洛決戰 → 中原安定。相同準備與第 5 關達標，取得「指揮接力」，等價解鎖諸葛亮；此時是及早分擔讓他不至於病倒，不硬塞五丈原死亡倒數。

全勝且 B=handover→〈漢室再曉〉，宛洛打通並建立接管秩序，結尾呈現漢室重建的起點，不宣稱七關已征服所有天下。全勝但未交接→〈北望中原〉，戰略突破而承接未成；未全勝→〈兩路未竟〉，保留荊州與已達成果。

龐統獲救／在隊：雙路計畫由兩位軍師分任；未獲救：由諸葛亮、法正及將領共同制訂，絕不出現死去的龐統。關羽在隊由本人領軍，僅 NPC 獲救則在適當年代以其部屬接旗交代。任何 S8 版本第 7 關成功皆可解鎖姜維，不綁諸葛亮救援。

## 五、吳國：孫策活著，江東不必走回同一場二宮之爭

### 5.1 八章位置與接線

### 5.2 孫堅、孫策與周瑜都放回現有預算

U2.A：`scouts` 查追兵與沿岸情報／`rush` 追擊奪勢。
U2.B：`handover` 接應部隊及渡江分工／`solo` 主帥集中指揮。

U2 七關：峴山追兵 → 回旗接應 → 渡口立足 → 沿岸糧道 → 江東據點 → 城外整軍 → 太史慈對陣。

A=scouts、B=handover、通過第 2 關→孫堅獲救／同行接援成立。第二、三關之間以字幕交代時間流逝與孫氏交軍，**不回血、不重新結算、不增加選項**。父親存活不免除孫策後來遇刺的政治危機；父親可退居後方，孫策仍是出征者。

U3.A：`escort` 分路護衛／`hunt` 依舊輕騎出獵；B：`handover` 兄弟分任內外／`personal` 軍政一身承擔。U2.A=scouts、U3.A=escort、通過第 5 關→救孫策；本人在隊則為共同破伏。兄弟分政需孫策獲救或在隊，並且 U3.B=handover，不是只活下來就自動完成分權。

周瑜的休養接力放 U5 各版本前兩關：A=`medical` 設醫舟、輪值處理軍務／`press` 優先推進；B=`handover` 交出部分指揮／`retain` 主帥統攬。A=medical、B=handover、通過第 2 關→周瑜獲救／同行接力。原型病危是長期疲勞，此處以提早交接避免惡化，不必每條新線都讓他在同一張病榻等救援。

### 5.3 赤壁成功後，為什麼改打合肥

U4.A：`pact` 明訂與劉備互援邊界／`advantage` 優先自身戰果；B：`handover` 水陸分令／`personal` 主帥親掌。

**兄弟分政成立、A=pact、B=handover、U4 全勝**→U5 合肥。孫策帶領進取派，孫權維持江東行政，周瑜與魯肅使軍事與同盟配合；新的政治分工讓赤壁勝果用於北進，不再把下一章寫成搶荊州。

未齊備→U5 荊淮，維持既有爭奪與守江主題。赤壁可以在敘事上取勝，但未具備乘勝北進的條件；戰前清楚列出北進目標。

### 5.4 U5 合肥 → U6 淮泗／江防重整

合肥七關：醫舟護運 → 水軍交接 → 濡須渡口 → 江北補給 → 合肥外圍 → 城門合擊 → 淮南立足。前兩關已是本章的一部分，後五關才是北進；全勝→淮泗，否則→江防重整。

荊淮七關：醫舟護運 → 水軍交接 → 荊州使節 → 江岸對峙 → 淮口守備 → 糧運保全 → 江防換守。依關羽在隊與否，後續改江岸止兵或基礎夷陵。若有其他跨國人物改寫死亡因果，亦必須套用止兵版，不得為了章名強殺隊友。

**U6 淮泗**：孫氏有了江北據點，面臨的不是再來一場夷陵，而是如何留下軍民、穩定淮泗。

- A：`settle` 軍民安置／`advance` 追擊擴張；B：`local` 地方分任／`central` 中軍統管。
- 七關：淮南守備 → 流民接護 → 舟車糧運 → 魏軍反攻 → 淮泗渡口 → 兩岸聯防 → 新郡安定。
- 全勝→U7 兩岸立政；未全勝→U7 江防整軍。失敗保留 U5 的立足成果，但擴張停止；不把合肥全勝抹掉。

**U6 江防重整**：合肥未取，撤回江岸重新整軍。A：先護民／先護械；B：分段接防／中軍掌令。七關：退軍接應 → 軍民渡江 → 殿後護舟 → 濡須復防 → 糧倉保全 → 水寨換守 → 江面解圍。任一結果都進 U7 江防整軍；不能一場整軍就當作補回淮泗拓土。

### 5.5 U7 建立制度，U8 才是它接受考驗的時候

U7 三種版本共用 A：`charter` 公開軍政章程／`orders` 軍令優先；B：`handover` 交接軍權／`retain` 元老留權。

**兩岸立政七關**：新郡護運 → 徵糧糾紛 → 軍民分防 → 舊部抗令 → 邊軍輪替 → 章程護送 → 兩岸交防。A=charter、B=handover、全勝→U8 建業共治；否則→U8 江東議局。戰鬥對象是破壞交防、劫糧與抗令的武裝，議政發生在章內對話，不新增辯論戰役。

**江防整軍七關**：散軍歸建 → 糧道清理 → 江口拒敵 → 舊部整合 → 水陸換防 → 軍令護送 → 濡須穩守。所有結果→江東議局，保留前兩章具體據點狀態。

**石亭版**沿基礎七關。孫策在隊或本夢獲救→江東議局，因兄弟／舊部留下的權力安排改變；否則→二宮。不能讓活著的孫策毫無解釋消失，再強套同一場二宮之爭。

### 5.6 U8 三種政治局勢，同一個終章位置

共用 A：`hearing` 公開聽取諫言／`secret` 密議處置；B：`handover` 落實交接／`retain` 主事者保留終決。

**二宮**：孫權晚年立嗣衝突，陸遜受到排擠。七關：呈議護送 → 宮門對峙 → 諫臣家眷 → 江岸接援 → 陸遜出局 → 禁軍交令 → 宮城止兵。

**江東議局**：孫氏舊部、拓土派與江東士族爭奪軍政權。若孫策仍在隊，由本人面對自己留下的集權；僅 NPC 獲救則依年代由其交政制度或舊部延續影響。七關：議政護送 → 軍令分歧 → 江北糧道 → 諫臣保全 → 陸遜呈議 → 水陸交令 → 建業止爭。不能不問國勢又把它叫作二宮。

**建業共治**：兩岸制度已立，孫氏從征服者轉成維繫秩序的人。陸遜提出通商與輪調，元老擔心軍權被削弱。七關：商路護運 → 港口整備 → 海陸糧運 → 元老議政 → 陸遜主議 → 軍民交防 → 海陸通商。

所有版本：U7.A=charter、U7.B=handover、U8.A=hearing 且通過第 5 關，解鎖陸遜。危機版是保人，共治版是讓其改革取得正式保護與議事資格；記錄分別命名，不假稱他都曾被逼死。

共治全勝＋B=handover→〈江海長明〉；全勝但未交接→〈繁華待續〉；未全勝→〈共治未竟〉。另外兩版須上述陸遜成果＋B=handover＋全勝，才是〈江月長明〉；其餘按保人／止爭程度結束。任何結果都在 U8 收束。
