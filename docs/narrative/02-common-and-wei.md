# 共通開場與魏國篇：把天下扛起來

以下是逐章主線劇本初稿，A／B 各含兩個可實作分支；日常隨機委託仍沿用現有內容池。括號內為穩定選項值。戰役回收另依通關數播放，不把本隊的敗退直接寫成國家滅亡。

## 共通 C0｜黃巾之亂：第一個要帶回來的人

現有 ID：`ch:camp.yellowturban`。R1–8。開場仍在皇甫嵩帳下。

**入章。** 鼓聲裡，你發現自己的手正在發抖。旁邊的新兵阿禾把槍往你掌心一塞：「握住。等會兒誰先跑，誰請吃飯。」皇甫嵩巡營走過，停了一步：「怕很正常。別把身旁的人忘了。」

**A｜倉門裡的人。** 潰兵藏入糧倉，裡面還有避難百姓。

- 開側門接人（`shelter`）：你帶人拆開堵門的車架，阿禾守住出口。「先過人，再過糧！」結果：百姓脫困，追擊稍緩；記護民。
- 奪外寨斷援（`secure`）：你先奪通道，再逼倉中交械。「路在我們手裡，誰也不必死守這道門。」結果：俘虜交械，軍需保全。

**B｜缺席的點名。** 清點時，發現一隊運糧兵未歸。

- 親自循旗尋人（`return`）：你帶回隊伍，阿禾掏出被壓扁的乾餅：「欠你的飯，先付一半。」結果：全員歸隊；記護民。
- 教新伍長循號接應（`handover`）：你畫出辨認友軍的旗號，讓新伍長分隊接回散兵。結果：新伍長第一次獨立完成任務；記交接。

**七關。** 村外哨卡 → 運糧小道 → 柵門 → 黃巾前寨 → 被圍車隊 → 主營旗陣 → 張角夢影。最後一關為明示的夢境試煉，張角形象散成黃巾，預留未來勢力，無復活宣告。

**章末。** 皇甫嵩把你的名字補進功簿：「現在算是我帳下的人了。」袁紹的討董檄書隨軍令到來，三家使者在營外招募；你將選擇第一面真正跟隨的旗。

成果：「阿禾朝你比了比半塊乾餅：『回來再算。』」代價：「援軍替你守住最後一段路。你把這份援手記在心裡。」全通：「張角夢影看了你一眼：『若下一回，你站在另一邊呢？』」

## 魏的人物群

曹操是願意把難題交到你手裡的主公，也會被你當面攔下。荀彧負責問「做成以後，還守不守原先那句話」；郭嘉負責看見險中那條活路；張遼、夏侯惇、于禁承接軍中夥伴戲。後段加入曹丕、司馬懿、曹爽作劇情人物，是否成為可用名士另行製作。

原創隨軍書吏阿禾可反覆出場，從一個名字簿把各章串起來。夢中年齡折疊不用解釋成不老之術；跨世代場景改用「舊部帶出的新一代」。

## W1｜虎牢關：敢跟上那面旗嗎

現有 ID：`ch:wei.hulao`。R9–16。

**入章。** 諸侯帳中酒尚未冷，前線又抬回一面折旗。曹操把酒放下：「再議下去，洛陽就只剩灰了。」他望向你：「你帶幾個人，跟得上？」

**A｜盟軍的空缺。**

- 補上前線（`vanguard`）：你領兵換下久戰的隊伍。曹操：「好！先讓他們知道，有人肯來。」結果：前線穩住，建立武官向敘事。
- 修通接糧路（`supply`）：你徵集車馬、重排運糧班次。荀彧：「肯把路修好的人，比肯喊衝的人少。」結果：軍糧接續。

**B｜追兵與流民。**

- 開道護送流民（`shelter`）：你把車陣轉向人群，承諾將他們送至後營。結果：記護民；曹操收下你呈報的人口冊。
- 交副將守糧台（`handover`）：你讓副將獨立掌管援糧令。結果：記交接；親兵不再件件事只等你命令。

**七關。** 關外游騎 → 拒馬陣 → 李傕部 → 關下營寨 → 華雄 → 西涼親軍 → 呂布。沿用演義舞台，勝末關是擊退其突擊，不宣告呂布死於此地。

**章末。** 洛陽火光照紅帳幕。曹操將各路回報壓在地圖下：「這一仗沒做完的，咱們往後自己做。」成果：你的部曲整隊隨旗。代價：你帶殘隊歸營，曹操命人給你騰出熱食。全通：呂布回馬望你一眼，記住了你的旗。

## W2｜官渡：把不可能拆成七步

現有 ID：`ch:wei.guandu`。R17–24。章首以短蒙太奇交代迎奉天子、屯田及北方對峙，不倒置時間。

**入章。** 對岸營火鋪到天邊。郭嘉借你的手遮住半張地圖：「看全部，誰都怕。看這一處，就有辦法。」

**A｜最後一批軍糧。**

- 軍民共保屯倉（`granary`）：你把徵糧改成有定額的輪供，留出種糧。結果：糧道穩住，為後續魏國策提供民生前置。
- 切斷敵方轉運（`raid`）：你組夜襲小隊，先奪轉運情報。結果：敵軍分兵，為奇襲敘事提供前置。

**B｜來投者的一封信。**

- 親率精兵驗路（`verify`）：你不要求眾人相信一句話，先把沿線暗哨逐一帶回。曹操：「路驗明了，我與你去。」結果：突擊方案落定。
- 把破敵圖教給副將（`handover`）：你把分路接應講到每隊都能復述。結果：記交接；即使你被阻，另一隊仍能接上。

**七關。** 白馬外圍 → 延津渡口 → 壕溝陣 → 運糧營 → 烏巢外哨 → 烏巢火線 → 袁軍追擊隊。屬戰役剪接，不把不同交鋒壓成同一天。

**章末。** 北方營火一片片熄下，軍中先是寂靜，隨即歡聲奔湧。郭嘉把你的手移開：「現在，可以看整張圖了。」成果：你帶回撤出的斥候。代價：友軍完成主攻，你替傷兵守住退路。全通：你的旗第一個從火線裡穿回來。

## W3｜平定河北：給勝利留一條回家的路

現有 ID：`ch:wei.hebei`。R25–32。北地長征作章末場景。

**入章。** 郭嘉一邊咳，一邊把北地小道畫得像酒館菜單。你按住他又要伸向酒壺的手。他笑：「怎麼，你也要管我？」

**A｜前鋒催行。**

- 建驛站、備醫隊（`relay`）：前鋒少領一批快馬，後路增設接應與病卒轉送。郭嘉：「行，你替我把回程也算上。」結果：改命 D-W1 第一準備。
- 集中輕騎奔襲（`pursuit`）：你搶下關隘，縮短正面追擊。結果：當章武功敘事收益；郭嘉原命運維持。

**B｜軍師不肯離營。**

- 請郭嘉留後方統籌（`rest`）：有 `relay` 才能採用完整方案；沒有時仍能勸休，但提示不足以完成改命。郭嘉在傳令圖旁重新坐下：「前面那一手，交給你了。」
- 讓副將接管前鋒（`handover`）：郭嘉仍隨主力，你完成部曲交接；記交接，走常規線。

**七關。** 河北外營 → 斷橋 → 城下壁壘 → 北地驛口 → 山道伏兵 → 白狼前陣 → 蹋頓部。

**章末。** 常規：捷報後送來郭嘉病逝的消息；曹操留下他未喝完的酒。D-W1 成功：營帳傳來熟悉的咳聲，你掀簾，郭嘉把熱湯舉得像酒：「這杯，算我服你。」代價／成果分別寫驛兵損失與有序返營，不另改人物生死。全通：追兵被擋在最後一座驛站外。

## W4｜赤壁：火起之前，先把人帶出去

新 ID：`ch:wei.chibi`。R33–40。

**入章。** 大江上船燈如城。你看見笑談南征的將士，也看見不斷擴大的病營。曹操站在船頭：「這江，總得有人跨過去。」

**A｜船隊整備。**

- 留側航道與救生舟（`boats`）：放棄整齊密列的排場，保留撤離空間；記護民。郭嘉若存活，與你一起推演火起後的調度，不預知一切。
- 強化前列攻船（`assault`）：集中資源準備突破聯軍。結果：前鋒作戰向收益，救援由友軍承担。

**B｜江上不對勁的風。**

- 親自帶第一隊撤離（`evacuate`）：你先把病兵送上救生舟，再回火線接應。結果：記護民；是 D-W1 後續回收。
- 交各船長獨立解纜權（`handover`）：不再等待一艘船上的總令。結果：記交接；分隊得以自救。

**七關。** 江岸前哨 → 聯軍小舟 → 火船逼近 → 煙中纜橋 → 病營撤離 → 華容岔道 → 聯軍追兵。

**章末。** 基線為南征受挫，不因玩家七關全通統一天下。成果：你的救援旗從煙裡一次次出現。代價：你被友軍拖上最後一艘船，後續補充兵員。全通：你斷後歸來，曹操下馬替你接住搖搖欲墜的軍旗。郭嘉存活時補：「這回換我在岸上等你。」

## W5｜潼關：敵陣能破，人心也能收

新 ID：`ch:wei.tongguan`。R41–48。

**入章。** 河灘風沙遮面，西涼鐵騎的蹄聲已能聽見。曹操指著防線缺口：「能打穿。可打穿以後，誰替我守住？」

**A｜渡河部署。**

- 穩住渡口與鄉里（`settle`）：你約定補償徵用的船隻，確保返航不斷。結果：記護民，民生路線前置。
- 領騎撕開側陣（`charge`）：你與前鋒分進，打出新的渡河空間。結果：武官向收益。

**B｜降卒來營。**

- 編入共同軍籍（`register`）：把降卒交給明定軍法保護，不交由私人處置。結果：制度路線前置。
- 訓練新校尉共守關隘（`handover`）：你與新校尉演練接防，移交旗令。結果：記交接。

**七關。** 渡口游騎 → 河灘箭陣 → 西涼前鋒 → 夾道 → 馬超突擊隊 → 聯軍中陣 → 退路爭奪。

**章末。** 收兵時，昨日的敵卒正與你部下一起抬車。成果：渡口按你立下的規矩運轉。代價：你先護住渡船，關隘由其他部隊接手。全通：你單騎回到旗前，背後的隊伍重新結成一線。

## W6｜漢中：這一退，也由我來帶

新 ID：`ch:wei.hanzhong`。R49–56。

**入章。** 山路一夜落雨，蜀軍的鼓聲從雲下傳來。軍議爭到最後，曹操問的卻是：「若退，能帶回多少？」

**A｜山道物資。**

- 備接力糧站（`relay`）：你把大隊拆成能互相支援的縱隊。結果：民生／持久戰前置。
- 集中守住主隘（`fortify`）：你替撤離換取時間，主打軍事國策。

**B｜撤軍次序。**

- 先送居民傷兵（`shelter`）：你留下斷後，把車位讓給走不動的人；記護民。
- 分授撤軍令旗（`handover`）：各隊不必擠在同一路口等主帥；記交接。

**七關。** 山口接戰 → 林間弩陣 → 定軍山外圍 → 糧道守備 → 蜀軍追擊 → 窄谷護送 → 最後接應。

**章末。** 基線是漢中轉入蜀方掌握。成果：你把名簿擺在曹操面前，還來得及一個個點名。代價：你帶回殘隊，曹操讓新兵接替疲憊的斷後者。全通：最後一面旗越過山口，你親手斬斷追兵渡橋。

## W7｜新朝：把承諾寫成誰都能看的字

新 ID：`ch:wei.succession`。R57–64。章首交代曹操去世與曹丕承接權力，玩家進入新朝。

**入章。** 舊主的佩劍留在架上，新詔書送進帳中。曹丕問你：「父親留下的人，願不願意替我把這一步走完？」你望向窗外，當年的同袍都在等你的回答。

**A｜交接詔令。**

- 公開軍籍與調兵規程（`charter`）：把驗印、覆核、緊急守備寫明，曹丕核可。結果：D-W2 第一準備。
- 優先整合軍令（`centralize`）：你支持迅速統一各地命令，選擇中央強軍路線。

**B｜誰來接你的班。**

- 多署共驗、培養接班人（`handover`）：讓新將領共同演練合法調兵流程；記交接，D-W2 第二準備。
- 親掌精銳護京（`guard`）：你擔下最急迫的保衛任務，保留軍事路線。

**七關。** 京畿外道 → 詔書護送 → 偽令截查 → 倉城守備 → 邊軍換防 → 橋頭解圍 → 禁軍會合。敵人是武裝攔截與混亂部隊，非用戰鬥替代登基儀式。

**章末。** 曹丕念完你的奏議，將舊印放回匣中：「這一次，用新印。」成果：各地順利接令。代價：部分軍鎮延後接防，由朝廷援軍補位。全通：最後一支遠鎮部隊持印到京，滿場旗號首次同向。

## W8｜高平陵：輪到你攔住這場風暴

新 ID：`ch:wei.gaoping`。R65–72。明示多年後、兩次皇權交接已過；曹爽與司馬懿對峙。

**入章。** 天未亮，城門已換了守兵。年輕副將攥著兩封互相矛盾的命令：「將軍，聽哪一封？」你拿起早年留下的調兵規程：「先看，誰越過了這條線。」

**A｜政變當日。**

- 按公開規程保護朝議（`audit`）：若 W7 兩準備齊全，啟動 D-W2；否則只能護送少數官員，不宣告止亂。
- 先護送城中家眷（`shelter`）：你組織安全通道，記護民；常規權力更迭在背景發生。

**B｜勝負之後留什麼。**

- 公開交接、交出私人兵權（`handover`）：記交接；D-W2 成功後，這是保住成果的必要選擇。
- 留任統軍、穩住邊防（`guard`）：軍事國策承諾；若已止亂卻選此，僅完成階段救援，不給制度改命終局。

**七關。** 城外哨道 → 武庫封鎖 → 太倉糧路 → 洛水渡橋 → 官員護送 → 政變軍前鋒 → 朝議外城。以拿下通道、逼出議事空間為目標，不擊殺司馬懿來代替政治後續。

**章末。** 常規：朝中換了位置，你帶著部曲與承諾走向自己的歸宿。改命：兩邊將領都在同一張桌前解下佩劍，你站在門邊，終於等到第一聲正常的早朝鐘。成果：通道穩住。代價：護送受阻，改命挑戰未成仍照常結算。全通：年輕副將依你教的規程完成最後一道驗印，你沒有替他回答。

終章 B 後另開不耗回合的結局意向頁，依通用規則選國策、個人歸宿或已完成的改命紀念，不能被自動推進略過。
