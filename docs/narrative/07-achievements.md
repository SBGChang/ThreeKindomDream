# 成就：替值得記住的那一刻留名

首發 42 項設計提案，分七組，每組六項。用途是鼓勵玩家理解玩法、探索不同人生與回看自己的旅程。無能力、輪迴點、名士碎片、劇情鑰匙獎勵；只有解鎖演出、圖樣及描述。

目前程式有部分終身統計與結局收藏，**尚無完整 AchievementDefinition 或成就模組**。下表「可讀」指現有資料能提供判定原料，不代表成就已經可觸發。「新增」表示需補本局摘要、永久紀錄或事件訂閱。

## 口徑

- 單局條件只讀同一 `runId`；不同局的片段不能湊出一次單局成就。
- 完整序列＝本設計共通＋8 勢力章全部完成；與現行 `runsFullDream` 的稱號分類不同，不能直接混用。
- 結局成就只在正式結算成功入帳後解鎖。達到救援點可顯示劇情里程碑，正式「改命成就」仍須完成該主結局。
- 已完成兩條改命、只選一個作主結局時，另一條保留 `completedRoutes`，但它的「達成某結局」成就須在另一局正式選中該終幕。頁面明示這項差別，不偷偷一次發兩個主結局。
- 成就以固定 ID 記錄，重複事件、讀檔、重放結局不重複解鎖。收藏結局用集合去重。
- 除改命與全結局的劇透項外，所有條件預先可見。隱藏項可由玩家主動開啟劇透描述。

## 發布、擴充與獎盃牆

通用 11＋魏 5＋蜀 5＋吳 5＝26。第十二個通用條目「在野」暫不列入首發集合，因此不會卡住全收集。

每項全收集成就綁定固定清單版本 `narrative-v1`，不使用「目前載入了多少內容」作可漂移分母。未安裝所需包時標示需要該篇，不能因為只載 core 就顯示全三國完成。後續新增龐統、周瑜等改命線時另開新成就，不撤銷舊獎盃或擴大其條件。

舊存檔只能回填有證據的成就：既有 reachedEndings 可回填同 ID 的舊結局收藏，但「罷官→掛印長歌」語意不同，不把舊罷官直接當新選擇完成；保存 legacy 展示條目，重新達成新版本後才計 v1 全收集。沒有單局戰鬥紀錄的舊檔不能猜測「三人同時施放過技能」。

首次全收集演出：南華老仙將寫滿的冊子合上，玩家可翻看各結局留的一張小畫。他把新的空白冊放在旁邊：「還想去哪裡？」這是收藏演出，不追加第 27 個主結局。
