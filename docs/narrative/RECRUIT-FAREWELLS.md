# 一世結束・初次解鎖演出

已接入 20 位條件解鎖角色。完整逐句劇本位於 `content-source/recruit-farewells.ts`。

## 正式順序

本世所有劇情完成 → 顯示本世結算 → 玩家確認結算並保存獎勵 → 新解鎖人物逐一告別 → 各自顯示「XXX 解鎖」 → 收下最後一份約定後回到天命。

行動、升官、戰役與章末都不播放這段演出。條件達成時仍即刻保存相逢資格；待演出名單與資格分開。每人僅首次達成時入列，已解鎖的舊角色不補播；看完後再達成條件也不重播。舊存檔照常讀取，新解鎖者開始採用此流程。

每句切換保存游標，重開後接續同一句；每人最後是獨立系統解鎖卡，確認後永久標記完成。結算重入不重複發獎。儲存失敗時保留當頁並可重試。

## 驗收

- 無玩家存檔試看：`/scripts/fixtures/recruit-farewell.html`；可加 `?characters=guanyu,ganning,nanhua`。
- 試看進度僅寫自己的 sessionStorage；重開分頁可從頭看。
- `npx tsx scripts/tests/recruit-farewell.test.ts`：完整名單、世末門檻、首次授予、舊檔、讀檔、連播、重複輸入／結算、分支。
- `node scripts/verify-recruit-farewell.mjs`：20 人實際畫面、鍵盤、尺寸、試看讀檔，以及隔離瀏覽器中正式 App 的結算保存、接續與返回天命。
