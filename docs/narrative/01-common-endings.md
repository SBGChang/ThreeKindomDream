# 通用結局：你在夢裡成為了誰

設計稿；新條件未實作。演出採「一個動作、一個人的回應、一句收束」，讓稱號長在故事裡。結局發生於夢內，演完才回南華老仙處。

## 判定及稱號

先選唯一主結局：改命結局 → 玩家主動完成的勢力結局 → 通用特殊人生 → 官途結局。進入勢力最後一章時，明示「完成國策」或「寫下自己的歸宿」，後者不觸發常規勢力結局。已成功改命的玩家可以在終章選擇紀念哪一條完成路線；未選則按固定優先序取一條，見製作契約。

以下 `C`、`M` 分別代表文、武官階。數值沿用現有結局尺度作第一版候選，72 回合平衡後再調整。優先級為新配置提案，與現行數字不同。倍率列是通用結局的**單一總倍率提案**；沿用既有九筆倍率，新特殊人生取 1.4。不疊乘其他結局。

現有「罷官」只讀低官階，會把沒有失職的玩家寫成有罪；提案保留 ID、改名並補主動選擇條件。新「掛印長歌」是自由選擇的收束，不需要增加死亡或中途退休功能。

現有「功成」雖有兜底資料，卻被「≤1、≤2、≥3」完整遮蔽。新表讓 C=2、M=1 且未掛印等狀態可實際得到功成。這是設計層要修正的可達性問題。

在野仍保留舊觸發兜底，但現行魏勢力無入門條件，因此正常流程無法抵達。**暫不納入首發收集分母或全結局成就**。不為增加一個結局而臨時加入拒收玩家的機制。

副標「官途」只依官階選出最高稱號，供勢力／改命結局展示；不另入冊、不另結算。通用特殊人生須有先前準備，未達標的歸宿選項顯示缺少哪些章節，另有「功業留名」可選，永不卡住結局。

## 十二段結局正文

### 出將入相

你把劍放在案旁，先批完最後一份春耕文書。城外是等你校閱的大軍，城內是等著開市的人。昔日跟你分過半塊乾餅的老卒，抱著新做的官服笑道：「這下可好，文的武的，都得找你。」

你披衣出門。百官讓出一條路，將士舉起一片旗。當年想站上去的地方，如今終於有了你的名字。

### 丞相

群臣還在爭論新渠該由誰署名，你已捲起衣袖，踏進河泥裡。第一股水越過閘門，兩岸百姓的歡聲蓋過了所有奏議。

年輕的書吏追來，急得把「丞相」喊破了音。你回頭，把印交給他保管：「先別讓它掉水裡。這件事，我等了好多年。」

### 大將軍

最後一座敵營降旗時，你沒有先進城。你沿著隊伍一個個點名，直到那個總是落在後頭的小兵也舉起手。

「全了？」你問。

「全了！」千軍回聲震動山谷。節鉞送到你面前，你舉起它，指的卻是歸途：「回家！」

### 尚書

新來的同僚問你，滿屋公文究竟哪一份最要緊。你抽出一张被反覆退回的小小請求：邊城的學舍，少一扇過冬的門。

來年春天，遠方送來一封歪歪斜斜的謝信。你的名字沒登上那日最大的捷報，卻被一群孩子端端正正地寫在第一頁。

### 四方將軍

城頭換上你的旗號。老兵試著叫你「將軍」，叫了兩次，還是忍不住喊回當年的綽號。你佯怒追打，滿營笑成一片。

夜裡警烽亮起，你第一個披甲。眾人也一個不落地站起身。你知道，這個名號真正的分量，正在那些跟上來的腳步裡。

### 功成

功勞簿上，你的名字只佔一行。你盯著它看了很久，直到同袍把你拖去喝酒。

「嫌少？」他問。

你搖頭，把那張抄本仔細收好。那一行裡，有第一次沒握穩的槍，有不敢接卻終於接下的差事，也有你一路走到這裡的證明。

### 布衣一夢

城門開了，你背著行囊走進人群。沒有人高唱你的官銜，但街角的湯攤認得你，曾與你同行的孩子也認得你。

「下次還來嗎？」孩子問。

你把碗放下，笑著點頭。這一夢，你還沒有站到最高處。可你已經知道路從哪裡開始。

### 掛印長歌

你把官印擺正，連同那份不願再署名的公文留在桌上。出門時原以為無人相送，卻見幾名老部下帶著酒，坐滿了台階。

「不做官了，總還能喝一杯吧？」

你解下束得太緊的腰帶，坐到他們中間。天很亮，前面的路也還很長。

### 在野（保留）

三封招募書都沒有留下你的名字。你把它們折成小船，放進村口的溪流。正想學人說一句看破世事的話，隔壁便喊你去幫忙抬梁。

你笑了一聲，捲袖過去。天下暫時沒給你位置，這一端的屋樑，倒恰好缺你一個人。

### 解甲歸田

卸下甲的第一天，你起得比出征還早。種下去的苗歪了半行，路過的老農毫不客氣地替你重種。昔日同袍隔著田埂大笑，說大將軍也有輸的時候。

你抹掉臉上的泥，把另一把鋤頭丟給他：「少看熱鬧。今天這一仗，咱們一起打。」

### 桃李成蹊

兩個學生為一道兵題吵得面紅耳赤。一人說該進，一人說該守，最後一起看向你。你把舊地圖攤開，卻沒有指向任何一條路。

「先說清楚，你們要帶誰回來。」

窗外又一隊年輕人啟程。你曾經走過的遠路，如今有更多人能走得比你更遠。

### 萬家燈火

入夜後，你登上修好的城樓。每一條街都亮著燈：藥鋪、飯館、重新開門的學舍，還有那戶終於等到家人回來的人家。

送來封賞的使者找了你半天，問你還想求什麼。你指著滿城燈火，許久才答：「這些，請讓它們一直亮著。」

## 夢醒的一句話

南華老仙只點出玩家的選擇，不否定夢中成果。通用成功：「這回的名字，你可喜歡？」布衣：「路認得了，下回便走得更遠。」主動歸田：「原來你也知道，何處便是終點。」改命成功改用其專屬收束。

新特殊人生與掛印長歌建議標為圓夢；布衣／在野沿用未圓夢。這會改變 `runsFullDream` 的含義與部分統計結果，須隨內容版本一併定義，不能只更換文字。
