# 角色、IF 與戰場事件整合紀錄

日期：2026-09-17。

## 可在正式遊戲使用

- 魏、蜀、吳各 12 位角色，另有群雄呂布；18 位初始開放相逢，19 位依故事或成就解鎖。解鎖與本輪隊伍分開：本輪達標會保留資格，後續入夢才進入相逢清單。既有存檔已收錄的角色保留。
- 每條路線仍為共通篇＋8 章，每章 8 次養成、7 關戰場；合計 72 次養成。替代劇本沿用原章節編號與數值曲線。
- 魏：赤壁反攻成功後，漢中位置替換成都；成都成功接北拒匈奴，失敗回新朝；北拒成功接治世之能臣，失敗回高平陵。治世結局須完成西域交涉。
- 蜀：落鳳坡救援接雙謀漢中；保留荊襄援路並完成戰果，接荊襄會盟，再接中興漢室。
- 吳：救回孫策或孫策同行、兄弟交令、赤壁履約後接合肥；成功推進淮泗、兩岸立政、大航海，受阻改接江防重整／江東議局。大航海結局須完成風暴救援與和平通商。
- 同行角色改用合作對話；原本相同姓名的敵將由守關敵將替換。替代線優先，不把大航海等新劇本蓋回原始救援事件。
- 戰場事件由資料指定關序、对話、選擇、單挑、輪流接牌舌戰、屬性檢定與獎勵。兩軍實際交手後觸發；全弓兵以第一次受擊觸發。對話／對決期間凍結主戰場，結束接回原戰場。
- 虎牢：第一次邀戰對全盛呂布；退讓後有張飛、關羽、劉備依序 AI 對戰與疲憊對話，再邀玩家挑戰。正式勝利發放對應名器、金錢、能力與呂布解鎖；讀檔或重複輸入不重發。
- 正式戰場舌戰使用本次重新編排的接牌玩法，保留示範頁的自行配將功能。

## 道具實裝

逍遙津令仍為 ★4，逐階累加：張遼統格權重 10→40、好感成長 +150%、單名士格 ×2、張遼同框 +100%、統成長 +40%、單名士格再 ×2（兩階合計 ×4）。

所有基礎成長加成用整數；原本實際效果已是 +2／+3／+4／+5，修正文案小數與企畫不一致處。

新增方天化戟、赤兔馬、倚天劍、白馬護符、荊襄盟書、四海航圖、通商文牒。戰前配裝分武器、坐騎、寶物各一格；七件新裝備只有本體階，不出售或產生無用途的升階碎片。舊有養成道具沿用原規則。入夢攜帶仍為兩件。

圖鑑顯示全部 20 件道具的效果與實際取得來源，包括未取得物品。原企畫的「追加來源提案」不是每一項都另增事件：本次實際來源以遊戲圖鑑為準，既有人物鏈與商店保留。

## 驗收與目前限制

- `npm run verify`：型別、內容、模組、戰場、單挑、舌戰、美術引用、劇情整合檢查。
- `npm run build`：正式打包。
- 新增劇情測試覆蓋固定長度、三國成功／失敗分支、相逢條件、真實接戰、暫停、還原、獎勵冪等、裝備傷害／治療、商店折扣、舌戰隨機狀態還原。
- 瀏覽器驗收：正式 Session 的出戰→接戰→原養成對話樣式→邀戰選擇；正式戰場舌戰暫停與恢復。
- 馬超、魏延、法正、姜維暫用共用美術；目前沒有這四人的獨立立繪與動作圖。舌戰也仍共用出招動畫。
- 新增分支已有可跑的部署對話、關卡情境及結局，但文案屬首版；本次驗證流程正確，尚未完成所有新獎勵和難度的長期數值平衡。
