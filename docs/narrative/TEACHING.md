# 教學與訓練修正

- 訓練只列出已解鎖／已持有的技能與特性。常階不再自動開放購買；空清單顯示等待傳授的說明。
- 教學直接取得第 1 級，之後每次同招教學直接增加 1 級，不收費、不受訓練的能力或章節門檻限制。
- 該項能力已達上限時，改發其最後一級訓練原價的金錢。技能常／良／絕為 240／500／1100；特性為 180／420／900。沿用內容價格表，不另寫死數值。
- 教學有獨立來源帳號，重播同筆事件、場景或戰役獎勵不會重複升級或領錢。劇情完成確認後才入帳，展示預覽不改狀態。
- 移除同行共事直接傳授。人物事件由主角對面的主要人物授課：★1 常階技能、★2 常階特性、★3 良階技能、★4 良階特性、★5 絕階技能；該人物沒有對應階級時複習已會的較低階招式。沿用人物原本的招式表、事件好感與前置鏈門檻。
- 主線場景支援 teachings，包含分支回應、章末與救援場景。黃巾章末授予沉毅；蜀線前六章章末分別授予突陣、廉德、火計、料敵、屯田、陷陣。原有戰役指定教學也共用突破／折金規則。
- 孟德新書、奉孝遺書原本的直接解鎖效果改為統／智系訓練折扣，避免道具繞過教學。
- 舊存檔已被傳授的未學習項目補為第 1 級；原先已持有項目及等級保留，不倒扣金錢或重領教學。
- 獎勵對話依實際差額顯示解鎖、突破、折金；滿級折金不再混入另一行額外報酬而重複顯示。

驗證：143 項模組測試包含直接購買拒絕、同格不教學、重播冪等、帳本守恆、事件實際結算、劇情預覽／領取／讀檔與舊局相容；雙救援正常流程仍通過。先前 gold-story-balance.json 是本次教學修正前的基準，不代表本版完整數值掃描。
