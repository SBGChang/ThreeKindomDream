# 《三國夢》劇情設計第一版

日期：2026-09-14。Main 本次只接收劇本、製作契約與整合交接資料，不修改 UI 或啟用新的遊戲流程。蜀篇非 UI 原型另存為 [整合補丁](integration/README.md)，供新版 UI 整合時參考。文中功能與數值均須區分設計目標與正式實作。

## 這一版要讓玩家記得什麼

你第一次入夢，想在史書裡留下名字。再入夢時，你記得那些沒能一起走到最後的人。等你終於能改變大事，你要親自站到那一刻之前，告訴他們：「這一次，我們一起回去。」

三條勢力線各有不同的主角處境：

| 勢力 | 想得到的東西 | 必須面對的矛盾 | 玩家在其中的作用 |
|---|---|---|---|
| 魏 | 讓失序的天下重新運轉 | 有效的權力，也可能成為無人能攔的權力 | 從能辦事的人，成為敢限制權力的人，或選擇替它開路 |
| 蜀 | 讓承諾有一個可以落腳的地方 | 對故人的情義，可能耗盡活人的未來 | 把仁義變成糧道、安置、交接與能履行的盟約 |
| 吳 | 讓江東的人守得住自己的生活 | 守住家業的手，可能把家人與功臣攥得太緊 | 連結宗族、將領、商路與繼承秩序 |

依使用者指定，採用**「熱血爽快、改寫遺憾」**的主調。日常有夥伴鬥嘴，戰場有並肩救援，長線準備要在決勝時刻兌現成看得見的逆轉。人物的弱點仍有因果，但不以說教或追加犧牲抵銷玩家的成功。救到的人會回來說話、參與後續，圓滿結局可以真心慶祝。

## 先固定的敘事規則

- **章節構成：共通 1 章＋各勢力 8 章；單局 9×8＝72 回合。** 魏既有虎牢、官渡、河北三章保留 ID 與相對次序。這是擴充目標；本次 Main 只接收劇本，未啟用 72 回合流程。
- **章序是人生的剪接。** 不把回合當一年，也不把數十年硬說成同一個戰役。合章時明示時間經過；各路線停在不同歷史節點，無須同年結束。
- **南華老仙負責夢外框架，皇甫嵩負責局內開場。** 不退回已被改掉的南華村求學流程。夢的時間可以折疊，事件的因果不能折疊。
- **關鍵抉擇保證出現。** 主線不是從名士隨機池抽到才有；沒有把關羽帶在陣容裡，也能在蜀線見到守荊州的關羽。劇情出場不等於可用指揮官。
- **固定事件四選一後處理事件佇列。** 現行四維是統、武、智、政；不沿用舊 GDD 的魅力、名聲、善惡值，也不恢復「鍛鍊或事件擇一」舊制。
- **戰役敗退也能過章。** 玩家本隊的七關表現決定救下多少人、保留多少成果；不因某一關輸了就強制戰死。世界大勢不自動等於本隊勝負。
- **常規線有自身價值。** 不救活歷史人物仍能得到完整、受尊重的結局。改命的代價主要是提前準備、放棄當下收益與完成挑戰；成功後不強迫另一個人代死，也不再用無法干預的悲劇把成果收走。
- **一局只有一個主結局。** 官途稱號可作副標；不把「丞相＋某國結局＋改命」當三次結局入冊，也不連乘三份結算倍率。
- **成就不供應能力或劇情鑰匙。** 成就只是紀錄；提示解鎖讀敘事閱歷本身，主線不讀成就系統。

## 每章的可玩劇本格式

每章提供兩個決策節點 A、B，安排在第 2、6 回合的事件佇列。選項標記就是穩定的敘事記錄，例如 `S3.A=rescue`。第 1 回合開場與第 8 回合戰前短句不另花回合。改命節點若落在同一章，直接擴充 A 或 B 的選項，不加第三輪強制對話。B 若是戰後方針，先選承諾、戰役後才依結果演出回應。

每章表列七關的名稱是**戰役情境提案**，不是已配好的敵人與平衡資料。政治章的戰役是護送、控路、撤離等軍事後果，不把辯論描寫成砍倒七名文官。

章末先播放依主線決策決定的世界結果，再接本隊回收：0–2 關為「代價」、3–7 關為「成果」。第 7 關另給一句特寫。世界結果的改寫必須符合改命條件，不能只靠七關全通。

首次劇情可展開閱讀；重玩預設顯示回顧短句，允許展開全文與略過已讀演出。72 回合含新劇情暫估 20–30 分鐘，屬待實測目標，不能繼續把舊版 10–15 分鐘當驗收承諾。

## 內容邊界與史實使用

所有台詞、民間角色及玩家介入皆為原創。基線使用三國歷史與熟悉的文學意象，明標「夢中改寫」的部分不當史實。虎牢關沿用遊戲既有演義舞台；不把三英戰呂布、借東風、七星燈寫成《三國志》記載。

本輪核對的原始文獻入口：郭嘉事蹟見[《三國志》卷十四](https://zh.wikisource.org/wiki/三國志/卷14)；孫策事蹟見[卷四十六](https://zh.wikisource.org/wiki/三國志/卷46)；諸葛亮傳可核對隆中規劃及北伐背景，見[卷三十五](https://zh.wikisource.org/wiki/三國志/卷35)；荊州爭奪的吳方人物脈絡見[卷五十四](https://zh.wikisource.org/zh/三國志/卷54)；陸遜事蹟見[卷五十八](https://zh.wikisource.org/wiki/陸遜傳)；吳國繼承紛爭見[卷五十九](https://zh.wikisource.org/wiki/三國志/卷59)。這些是改編參照，非整份虛構劇本的史實背書。

## 第一個值得做成可玩切片的段落

先做蜀第六至八章：「漢中準備 → 荊州救援 → 北伐交接」。這一段能一次驗證章節敘事、跨章記錄、戰役成果、兩種改命、專屬結局與成就。其前置狀態由開發測試檔提供，不要求先完成三國全部內容才看得到成果。
