# 三閣介面與美術方向

整體以 Q 版、熱血三國與《實況野球》式遊戲感為準：粗輪廓、圓潤厚實造型、清楚的色塊、亮色回饋與誇張道具比例。新場景應和既有武將相容，不採寫實宮殿或沉重古風。

- 風雲錄：武將索引、放大立繪與列傳頁，顯示星階、碎片與已開啟傳承。
- 天命閣：星象場景，五類命軌、階段星珠與點亮操作。仍使用原 catalog/purchase 規則。
- 天工閣（原天工鑒）：寶庫陳列、藏品選擇與器物詳情；未獲得的器物不假裝成已持有藏品。

三張最終場景使用內建 image_gen 重繪，原作曹操為風格參考；初稿偏寫實，未採用。最終素材存於 `public/art/realms/*-v2.png`，完整提示詞及來源記錄在 `realm-art-prompts.json`。介面邊框、按鈕及星珠由 CSS 繪製，以支援不同文字長度與狀態。
