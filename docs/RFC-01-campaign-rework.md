# RFC-01 · 大檢定改為戰役制

> **狀態**：**階段 A–D 已實作**（`fba98d3` 起）。數字有實測支撐（§6、§9），
> 但**手感未調**。未做的項目在 §5 逐項標了 ⬜。
> 本文件記錄**決議與遷移計畫**；模組契約見 [32 養成兌現](architecture/32_growth_conversion.md)、
> [33 戰役](architecture/33_campaign.md)、[23 特質與技能](architecture/23_skill.md)。

---

## 1. 一句話

**大檢定從「一次骰子判定」改為「一場七關的自動戰役」**，並補上養成與能力之間
一直缺失的那一層：**經驗值兌換**。

---

## 2. 為什麼要改

### 2.1 現況大檢定的四個問題

| # | 問題 |
|---|---|
| 1 | **六選一實際上是三選一，而三選一是在填一個風險偏好參數。** 路線那一維 8 回合前就決定了（練武的人看文路只會看到 0%），剩下三檔沿一條單調曲線走。全遊戲情緒最高的一格，是互動最少的一格 |
| 2 | **難度自選的張力只在最後一章成立。** 失敗代價是「剩下所有章節 ＋ 圓夢結局」，所以前三章貪心不是貪心，是算術錯誤。最優解恆定是「前面全穩、最後一章看情況賭」—— [policies.ts](../scripts/lib/policies.ts) 的 `rate` 策略正是這樣寫的 |
| 3 | **出戰名士是唯一的配置，卻零取捨。** 舊的 `ScreenCheck.tsx`（已刪除）預設 `eligible.slice(0, 3)` 塞滿，沒有成本、沒有排擠 |
| 4 | **那 8 回合的過程讀不到。** [roster-query.ts](../src/modules/roster-query.ts) 顯示 12 位名士在大檢定裡只貢獻一個 `sortieBonus`（1–8）。星階、碎片、好感、專長 —— 一整套系統塌縮成一個個位數的加法 |

### 2.2 一個結構性缺口

**沒有經驗值層。** [training.ts](../src/modules/training.ts) 把鍛鍊產出直接寫進
`AttributeState.values`。玩家因此沒有「這些點數要花在哪」的決策 —— 鍛鍊的產出
是既定的，不是可分配的。

**這兩件事必須一起改**：戰役制需要「特質與技能」作為配置素材，而特質與技能
需要一個購買它們的貨幣。分開做的話，任一半都不完整。

## 3. 決議記錄

以下每一條都是已定案的設計決定。**理由欄比決定欄重要** —— 它是未來想改回去時要先反駁的東西。

### 3.1 戰役的形狀

| # | 決定 | 理由 |
|---|---|---|
| D1 | 大檢定 ＝ **七關的自動戰役**，玩家在戰鬥中不操作（驗收型） | 玩家的技巧全投在**準備**上，與前 8 回合用的是同一種能力。操作型要蓋第二套與養成獨立的戰鬥平衡 |
| D2 | **場上只有一支軍隊**；三位名士是**傳令**，不在場 | 一條軍勢條因此是設定而非簡化；「夥伴為什麼不會倒下」不需要解釋 |
| D3 | 沒有三檔難度。**深度取代難度** | 難度自選從一個下拉選單變成問七次的同一個問題 |
| D4 | **每關打完都可以走**，走了保住已通過關卡的獎勵 | 見 D5 |
| D5 | **沒有及格線。** 第一關打完就走也能過章 | 「沒有任何一條路能殺死你，除了你自己按下『再打一關』」。**D54 把最後那一條也拿掉了** —— 現在連按下去也殺不死你 |
| D6 | ~~輸了 ＝ **夢醒**，整輪結束~~ | 殘忍是這個賭局的定價。**已被 D54 推翻**：擋住玩家的應該是牆，不是懲罰 |
| D7 | 膽小的懲罰是**難看的結局**，不是死亡 | 官階決定稱號、結算換點數 —— 懲罰早就寫在那裡了。D54 之後它是**唯一**的懲罰，所以結局階梯的下兩階改由「官階不足」達成（D56） |
| D8 | **不顯示勝率**，玩家自己判斷 | 你已經打過前六關，看得到自己剩多少血、上一關花了多少。資訊從「系統給的數字」變成「你讀出來的」 |
| D9 | **沒有回合上限** | 敵人的輸出本身就是時鐘：打得慢就多挨幾輪。前提是 D11 |
| D10 | 血量與資源**跨關累積、不回滿** | **這是整個設計的樞紐。** 若每關滿血重開，玩家進場前就能算出該在第幾關收手，七個決策點會塌成一個 |
| D11 | **恢復是有限資源**（糧秣），不是每回合自動回 | 否則續航是無條件正解，取捨消失 |
| D12 | 獎勵曲線**加速**（第 7 關值第 1 關的 **45 倍**，實測訂出來的），且**深處有唯一掉落** | 純數量的獎勵會讓玩家算出「我需要 X 功績」然後在剛好夠的那一關收手 —— 貪心又變成查表 |
| D13 | 部分獎勵是**戰力**（技能、道具、好感），兌現在下一場戰役 | 打得深 → 下一章更強 → 打得更深。早期決定因此高槓桿 |
| D14 | **收兵按鈕上必須寫著你放棄了什麼** | GDD §9.5 已立的原則（「避免玩家不知道自己放棄了碎片」）。看不見代價的「走」會讓 push-your-luck 退化成隨便按 |
| D15 | **跳過與快進第一天就要有** | 七場自動戰鬥第一輪好看，第五輪是阻礙 |
| D16 | 戰報必須是**因果鏈**，不是數字瀑布 | 驗收型玩家不操作，戰報是他**唯一**的資訊來源。看不懂的戰報 ＝ 不能玩又學不到東西 |

### 3.2 配置與施放

| # | 決定 | 理由 |
|---|---|---|
| D17 | 主角配 **3 招**；名士各帶 **1 招** | 「玩家部分比較暴力」。名士的招從他星階開放的池裡挑 |
| D18 | 四職能：**武＝物理輸出／智＝法術輸出／政＝恢復／統＝Buff** | |
| D19 | **主角不吃四職能對應** —— 四維決定他**怎麼打**，不決定他在隊裡的功能 | 沒有人想在自己的英雄故事裡當補師，而文武雙軌不能有一軌是廢的 |
| D20 | 主角每回合：**1 招保底 ＋ 第二招 60% ＋ 第三招 30%**，三次獨立擲 | 眾數落在 2 招（54%），期望 1.9 招／回合。**下限由玩家自己保證** |
| D21 | **先擲施放次數，再抽哪一招**；同回合**不重複** | 若第一格保底、二三格靠機率，玩家會把最強的招放第一格，三格退化成一格加兩張獎券。次數優先讓三格期望上場率相同（各約 0.63／回合）→ **配置從「排優先序」變成「設計一組組合」** |
| D22 | 名士每回合**各自獨立擲**，機率由**好感五階**決定 | 一回合可能三人齊發，也可能全都沉默。**上限由你的關係決定** |
| D23 | Buff 與恢復一律**作用在軍隊**上；**效果強度看施術者的能力** | |
| D24 | 恢復與 Buff 按**軍勢比例**計算，不用固定值 | 兵量在 12 階之間長 19.8 倍，比例制完全免除重新校準 |
| D25 | 敵人強度**索引官階**，不索引章節 | [17 §6.4](architecture/17_event_slot.md) 已立的規矩：難度與報酬必須一起長，否則壓低某一線的官階會變成刷簡單高報酬的農場 |
| D26 | 星階 → 他有**幾招可選**；好感 → 他**多常傳令** | 兩條現成的軸各給一個不重複的職責，都不碰他的數值。「配置固定」的原則保住，玩家仍有一個小決定 |

### 3.3 資源來源

| # | 決定 | 理由 |
|---|---|---|
| D27 | **血量只能用功績買。經驗買不到血量。** | 這讓單動作回合制第一次真的有兩邊：鍛鍊 → 經驗 → 你能打多痛；委託 → 功績 → 官階 → 你能撐多深。現在兩邊產出的是同一種東西，實測兩條路只差 12.3% |
| D28 | `兵量 = 1.0 × T[武階] + 0.5 × T[文階]`<br>`糧量 = 0.5 × T[武階] + 1.0 × T[文階]`<br>（`T` ＝ `careerRank.hostScale`） | 見 §3.4。單向判定會讓文官一滴血都撐不住 —— 因為文系的續航手段（政＝恢復）全部吃糧 |
| D29 | 功績從**門檻貨幣**升級為**你的血條** | 玩家不會再覺得升官只是為了解鎖 |

### 3.4 D28 的驗算

用 [hostScale](../content-source/core/career/ranks.ts)。灰盒四章單線約 1459 功績
→ rank 8；對分則兩線各約 730 → rank 6／6（數字已隨 D51 的新階梯重算）。

| 官途 | 武／文階 | 兵量 | 糧量 | 合計 |
|---|---|---|---|---|
| 純武 | 8 / 1 | **9.6** | 5.6 | 15.2 |
| 雙修 | 6 / 6 | 8.4 | 8.4 | 16.8 |
| 純文 | 1 / 8 | 5.6 | **9.6** | 15.2 |

**兩個要留下記錄的性質**：

1. **總量接近（15.2 對 16.8），差別主要在形狀。** 官階曲線的凸性懲罰了分散投資，
   而 0.5 那一項補回來 —— 專一與雙修是**形狀之爭，不是強弱之爭**。
   （新階梯下雙修多 10%，比舊階梯的 2% 明顯了一點，仍在可接受範圍。）
2. **0.5 那一項自帶防退化底線。** 純武官的糧量 5.6 裡有 4.8 來自他自己的武官階，
   因此「零糧秣」不可能出現，**不需要另加基底常數**。

而且因為 [attrLine](../content-source/core/config/training.ts) 已把四維綁在官階線上
（武／統 → 武功績、智／政 → 文功績），這條公式給的資源剛好是各自 kit 需要的那一種：

| | 輸出 | 續航手段 | 拿到的 |
|---|---|---|---|
| **武系** | 武＝物理 | 統＝Buff（**不吃糧**） | 大兵量、淺糧 |
| **文系** | 智＝法術 | 政＝恢復（**吃糧**） | 小兵量、深糧 |

武系靠大池子撐，文系靠把池子填回來撐。**這不是補丁，是兩套自洽的續航模型。**

| D37 | 解鎖**只在本輪有效**；圖鑑僅記錄「你學過什麼」 | 跨輪的預先解鎖若要做，走現有的天命商店，不在這一版 |
| D38 | 學習**不佔行動、隨時可做** | 它不是行動決策；而且數值會擋事件門檻，玩家有理由早花 |
| D39 | 道具三種降耗：**折扣／直接解鎖／階梯緩和** | 三種都接得上這次做完的 FuncType 系統 |
| D40 | 名士數值也在 **0–100** | 同一把尺，戰前配置畫面上四個人擺在一起可直接比。驗收型的資訊層靠這個成立 |

### 3.6 尺度修正（實測之後）★

實測第一版之後改的五件事。**四件都是同一個病因：0–999 時代的倍率鏈沒跟著換尺度。**

| # | 決定 | 理由 |
|---|---|---|
| D41 | **起始四維 15–30**，逐維獨立擲，不是 0 | 全 0 的第一場戰役打不出任何傷害（傷害吃 attr/50）；四個 G 也看不出角色性格；而 F 帶每點 4 經驗，前 20 點不構成決定 |
| D42 | **事上磨練走自己的曲線，與功績分開** | 兩者共用一條時，一則 ★4 事件會給掉 97 點經驗（一整個等級）。**分開的方向對了，但當時的曲線後來被 D50 換掉** |
| D43 | **功績的兩條倍率各自壓平**（19.8→12.5、9.0→2.8） | 相乘 178 倍讓一則事件就給掉階梯的八分之一，而複利失控：功績→官階→事件更值錢→更多功績。**壓一次不夠 —— 見 D51** |
| D44 | **戰役的關卡獎勵含經驗** | 章末那一格本來只給功績，而它是全遊戲最大的一筆。經驗走線性、不跟著 45 倍的功績跑。**「給該線的兩維」那一半被 D49 推翻** |
| D45 | **四維與經驗在外圍畫面就看得到**（現值、等級、未花經驗）；屬性**一點一點加** | 經驗是這個系統唯一的貨幣，藏起來玩家不知道手上有什麼。而只給「升一級」會把階梯藏起來 —— 階梯計價的重點就是「下一點多少錢」 |

**D43 推翻了一條舊的實測結論。** `rarityMultiplier` 當初從 3.4 抬到 9.0，
是為了讓「追光階」（`rarity-chaser`）與「追驚嘆號」（`flag-chaser`）成為取捨。
壓回 2.8 之後重測：**追驚嘆號 10542 對 追光階 10025 —— 只差 5.2%。**

那個 5.2% 是 D50 的動機：**兩個策略讀不出差別，因為兩邊都在放大同樣的兩種貨幣。**
分開索引之後（經驗吃稀有度、功績吃官階）那個取捨才有內容。

### 3.7 開局就有一招（第二輪實測）★

尺度改完之後，第一場戰役出現 **帶招「無」**。

| # | 決定 | 理由 |
|---|---|---|
| D46 | **入夢時就會一招** —— 起始四維最高那一維的常階招 | 消耗表的尺度讓第一章的購買力買不起任何一招（常階 140，八回合約攢到 100），玩家會帶著三個空格走進第一場戰役 —— 一招都放不出來，全靠指揮傳令。那不是「配置不好」，是**沒有配置可做** |
| D47 | 統與政**各補一條常階輸出招**（〈號令〉統·物理、〈亂辭〉政·法術） | D19 說主角不吃四職能對應，但內容裡只有武與智有輸出招 —— 抽到統或政最高的人自己一點傷害都打不出來。**D19 原本只是一句話** |
| D48 | 把 23 §6 的驗證表**實作出來**，並把最後一條換成「每一維都有常階輸出招」 | 七條驗證的實作是零條。D47 那個缺口讓 4 道 gate、81 項斷言全綠 —— 唯一擋得住它的驗證，就是 `starterSkill()` 的前提條件 |

D46 順手給「起始四維」第二個職責：**你抽到什麼底子，就會什麼**。
第一輪的自己不是白紙，而是一個已經有一手的人。

D47 的兩條招都比同維本行招弱一截（0.24／0.26 對 0.30／0.32）——
四條路都能打，但每條路都有它更擅長的那一手。名士不靠它們定位：
它們掛在 `star 1` 以上，名士的 `star-0` 一定是本行那一招。

### 3.9 兩種貨幣分家（玩家的五點回報）★★

玩家一次列出五點，而它們是**同一個病**的五個症狀：
**經驗與功績共用同一條倍率鏈，而階梯訂得太高逼著收入去追它。**

| # | 決定 | 理由 |
|---|---|---|
| D49 | **戰役經驗給四維均分**，不是該官階線的兩維 | 玩家指正「只給了我兩個屬性的經驗，這裡錯了」。舊做法把玩家的**主維排除在全遊戲最大一筆獎勵之外** —— 練智政的人打完七關，840 全落在他不用的兩維上。它同時讓 **政 成為唯一沒有自動來源的維**（實測 30–34），而政是恢復、恢復是深關續航的唯一手段：**想打深的人偏偏練不起政** |

### 3.10 牆取代懲罰（第三輪回報）★★

玩家一次提三件事，而它們指向同一個判斷：
**第一輪應該撞牆，而撞牆不該把三十二個回合歸零。**

| # | 決定 | 理由 |
|---|---|---|
| D54 | **戰役失敗不夢醒**，改為【已保住的獎勵減半】，章節照過 | 玩家：「大檢定失敗不會夢醒，但是就是獎勵直接變一半。」第一輪的玩家本來就只打得到第二三關（D57），那時他需要的是「撞牆、拿走能拿的、下一輪再來」。**擋住他的應該是牆，不是懲罰** |
| D55 | 小檢定失敗 ＝ **顆粒無收**（`failRatio` 0.4 → 0） | 玩家：「事件失敗後的獎勵還是高過上一檔的，所以玩家不害怕失敗，永遠選最高的就好。」對的：rank 8 ★2 的高檔**失敗**給 36，低檔**成功**只給 15。舊註解怕「高 DC 沒人敢碰」，實測是反過來 —— **沒人敢碰低檔**。「想穩」那條路由 D52 的 99% 過關率承擔，不由「失敗也有獎」承擔 |
| D56 | 刪除 `checkFailed` trigger 與〈戰歿〉；結局階梯的下兩階改由 **`sequenceCompleted` ＋ 官階上限** 觸發 | D54 之後局內**沒有任何死亡路徑**，`checkFailed` 的來源消失。〈罷官〉〈布衣一夢〉的本文本來就適用「走完了卻沒有前程」；〈戰歿〉的本文需要一個死亡，留著就是永遠拿不到的圖鑑格。`endingKind: 'aborted'` 因此改讀作**沒有圓夢**，而 `isFullDream` 量的東西從「你活下來了嗎」變成「你經營出前程了嗎」 |
| D57 | **敵方每回合輸出 ×2.6**，`DAMAGE_MUL` 改成與 `TROOPS_MUL` 同形 | 玩家：「第一輪還沒有天命能力就已經可以練到很高了……我預期只能打到 2、3 關。」實測舊值是 4.46–5.83 關。難度的旋鈕只能是**輸出**：兵力決定一關幾回合、輸出決定一關掉多少血，而 ×2.2 兵力的實測結果是**第一關要打十一回合** —— 難度到了，33 §5.4「一關五回合」那條規格沒了 |

**D54 的代價要記下來：走留的門檻掉到 1/3。** 獎勵曲線是加速的
（第 N 關 ≈ 前面全部之和），所以再打一關的賭注是「拿一半的已得換一倍的已得」：

```
p × 2B + (1 − p) × 0.5B ≥ B   →   p ≥ 1/3
```

損益兩平的勝率從五六成掉到 33%。實測（13 策略 × 300 輪）：

| margin | 意思 | 輪迴點數 |
|---|---|---|
| 1.0 | 算得剛剛好就上 | **7324** ← 最好 |
| 0.55 | 算不夠也上 | 7292（−0.4%） |
| 2.0 | 要兩倍餘裕 | 6681（−9%） |

**理性點仍然最好，過度謹慎被罰 9% —— 但魯莽幾乎不再被罰。**
走留仍然是決策，答案卻從「有把握才上」變成「沒把握也上」，
而**真正決定深度的變成敵人的強度，不是玩家的膽子**。
要把魯莽的定價拉回來，就把「一半」改成更少。那是一個未決的設計選擇。

**玩家對第一輪的規格三條全中**：

| 規格 | 實測 |
|---|---|
| 「只能打到 2、3 關」 | 深度 **2.57–3.82**，中位數 3.1 |
| 「一個 A，其他 CDE」 | `focus-civil` 智**85(A)** 統43 武40 政48 |
| 「兩三個 B」 | `dual-martial` 統**75(B)** 武70(C)（★ 這個策略是為了量這一條才加的） |

榜首仍然是**投資關係**的兩個策略：好感 → 指揮更常傳令 → 打得更深 → 更多特質。
整條正回饋的入口是「跟人相處」，那正是驗收型該有的樣子。

### 9.2 貪心的定價：兩次都動過 ★

**第一次**（戰敗＝夢醒的年代）：實測貪心是純劣，risk-averse 8554 對
risk-seeking 4765。兩個原因，都修了。

一、**變異蓋過訊號。** 一場仗只有兩三回合，勝負幾乎由「這回合放了幾招」
（28%／54%／18%）決定 —— 擲骰的變異比估計值本身還大。修法：`enemyTroopsByRank`
拉成四倍（一關約五回合），並把敵方輸出獨立成 `enemyDamageByRank`。

> **玩家算得出來的東西，才值得他去算。**

二、**深關的報酬不夠。** `REWARD_MUL` 從 18 倍拉到 45 倍 ——
一場戰役的價值有八成六在第五關之後。

**第二次**（D54 把戰敗改成獎勵減半）：整條 margin 軸的合理值下移。

```
p × 2B + (1 − p) × 0.5B ≥ B   →   p ≥ 1/3
```

| margin | 意思 | 輪迴點數 |
|---|---|---|
| 1.0 | 算得剛剛好就上 | **7324** ← 最好 |
| 0.55 | 算不夠也上 | 7292（−0.4%） |
| 2.0 | 要兩倍餘裕 | 6681（−9%） |

**理性點最好、過度謹慎被罰 9%，但魯莽幾乎不再被罰。**
那是 D54 的直接後果：走留的門檻從五六成掉到 1/3。
**要把魯莽的定價拉回來，就把「一半」改成更少** —— 未決。

### 9.3 九個實測才抓到的洞（沒有一個會讓任何測試失敗）

1. 替身 AI 只看軍勢比例就衝，全部死在第一場（通過章節平均 0.23）。
   改成算「我撐得住幾回合 ／ 對面要打幾回合」—— 那才是人在螢幕上讀的東西。
2. 純武系把用不到的糧量算進續航。糧秣只有帶了恢復招的人算得到。
3. 關底敵將的傷害少乘 `enemyDamageRatio`，華雄一擊 1587 打玩家的 762 兵。
4. **開局帶招「無」**：消耗表的尺度讓第一章買不起任何一招（D46）。
5. **統與政沒有任何輸出招** —— D19 在內容裡沒被實現（D47）。
   23 §6 列了七條驗證、實作是零條，所以這個缺口能在全綠的 gate 下活一整版（D48）。
6. **一則 ★5 人物事件在 rank 12 給 1680 功績，而那一階只要 1330**（D51）。
7. **政 是唯一沒有自動經驗來源的維**，而政是深關續航的唯一手段（D49）。
8. **高檔失敗（36）比低檔成功（15）多兩倍** —— 三檔退化成一檔（D55）。
9. **第一輪打到 4.9 關**，而規格是 2–3 關（D57）。

**第 6 到第 9 都是玩家先看出來的**，不是量出來的。模擬器印的是總量與終值；
那四件事要看【一則事件對照一階】【哪一維沒有來源】【失敗對照上一檔】
【第一輪走多深】—— 沒有一個在報表上。

> 這是這個模擬器的已知盲點：**它量得出分布，量不出「一個數字對照另一個數字」。**

### 9.4 三處未清的內容債

- `enemyNotables` 全部是空的。「選呂布當玩伴，虎牢關就不能靠他」
  這條機制在程式裡是活的，但沒有內容用它。**使用者明確延後。**
- 道具降耗只接上四件道具（D39 的三種只有第一種有內容用）。
- **〈戰歿〉已刪除**（D56）—— 局內沒有死亡路徑了。要拿回來需要一個
  死亡來源（例如「一關未過就戰敗 ＝ 全軍覆沒」），那是設計決定。
  25 §5 那條「每個 collectible 結局至少有一組可達的門檻」的驗證**沒有實作** ——
  它正是該抓到這件事的那一條。

## 8. 刻意不做

- **不做玩家在戰鬥中操作**（D1）。要操作就要蓋第二套獨立平衡的戰鬥系統
- **不做每人一條血條**。四條血條會把走留決策稀釋成一張表，而玩家反正不操作
- **不做名士陣亡**。倒下／缺席那個版本更有戲，但它是後續加法
- **不做文武各一種戰鬥遊戲**。同一套戰鬥、不同打法（D19）就已經是兩種玩法，成本只有一半
- **不做關卡之間的整補**（換招、換人）。push-your-luck 的張力來自「只能帶著現有狀態往前」
- **不做玩家自訂技能觸發條件**。那是「設定機器」的另一層，留待戰役玩起來之後
- **不做跨輪的解鎖繼承**（D37）
