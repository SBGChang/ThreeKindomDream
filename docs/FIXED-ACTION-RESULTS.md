# 固定行動：敘述與變化統計

固定行動單次演出 → 無頭像系統敘述 → 實際變化統計 → 同回合後續人物事件／委託，或推進回合。

敘述與統計均待玩家點擊場景任意非操作區，或 Enter／Space 繼續；不自動跳頁，不設繼續按鈕。超過四項變化則分頁。結算只執行一次，閱讀期间不推進回合。

## 結果與倍率

| 敘述 | 內部光階 | 固定行動成長倍率 |
| --- | --- | --- |
| 不順 | none | 0.8 |
| 一般 | silver | 1.0 |
| 成功 | gold / red | 1.5 |

倍率暫採此組初值；薪水、功績與好感沿用原規則。內部四個光階的抽取、升階及委託稀有度權重保留；不把光階名、品質邊框或事前精確成長預測展示給玩家。金／紅同屬成功收穫，因此倍率驗證改為正數、不遞減。

四類行動 × 四階職務 × 三種結果，共 48 段獨立敘述，位於 `src/ui/training-receipt.ts`。不直接顯示不順／一般／成功標籤，使用符合職務的事件敘述。

統計讀取結算前後真實差額，包含經驗、能力等級、金幣、功績、好感與晉升；受到上限限制的成長不會虛報。使用既有對話框美術，增益水藍色、損失紅色。

## 驗收

- `npx tsx scripts/tests/training-receipt.test.ts`：真實倍率、三種結果、實際差額、能力上限及 48 段敘述。
- 內容驗證、152 項模組斷言與完整建置通過。
- 開發用真實抽取種子入口：`?art=layout&fixed=bad`、`fixed=normal`、`fixed=success`；加 `&event=1` 測後續委託。入口不寫玩家存檔。
- 瀏覽器檢查：不順 192 經驗、一般 240 經驗；敘述與統計期間停在原回合，讀完後才前進。
