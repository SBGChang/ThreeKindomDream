# 橫版單機介面

## 啟動

雙擊根目錄「啟動遊戲.bat」，或執行 `npm run game`。它會先建置再開啟 Electron 獨立視窗；不依賴 Vite 伺服器。已建置後可用 `npm run game:launch`。

設計空間為 1280×800（16:10），視窗縮放時整體等比例縮放，剩餘空間留黑邊。F11 或遊戲選單可切換全螢幕。主畫面無頁面捲動，圖鑑、設定與修習使用覆蓋面板，長內容只在面板內捲動。

- 上方：章節、回合、輪迴點。
- 場景上緣：四維、成長進度、官階、學習點。
- 場景中央：同行名士，點選可查看好感與專長；部分名士尚以姓名印章占位。
- 下方：四項行動平均排列，點選即執行，同一屏完成本輪選擇。
- 事件：場景內對話框與應對選項，人物事件使用實際角色名稱。
- 底部：行旅、修習、器物與存檔狀態。
- Esc：關閉人物／手記面板、返回行旅，或開啟遊戲選單。

## 規則與存檔

本次沒有修改 Session、RunPolicy 或核心數值；畫面仍呼叫相同指令。`npm run sim:fast -- 100 flag-chaser` 可跳過畫面同步模擬。

本輪及天命存檔鍵維持原有格式。**Electron 與瀏覽器各有獨立的本機儲存空間**；切到桌面版不會刪除瀏覽器原有存檔，也不會自動搬移。桌面視窗關閉後，下一次開啟會恢復桌面進度。
