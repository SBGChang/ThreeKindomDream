# 單挑揭招與升變演出

出招後依序播放：2.13 秒壓黑揭招、0.25 秒恢復戰場、若我方升變則插入 2.8 秒特寫，最後 1.8 秒角色交鋒。一般選招仍不限時。

強化揭招：雙方圓牌由 12cqw 放大至 18cqw，保持尺寸，蓄勢 0.08 秒後以 0.26 秒加速衝入，接觸前不減速；0.34 秒第一次撞擊，短促彈開後 0.66 秒第二次撞擊；0.7 秒開始白光，消退後 0.94 秒才揭示結果。雙撞間隔與結果停留時間沿用前版。碰撞附短暫擠壓、旋轉及擴散衝擊環。Demo 與正式單挑演出改為逐影格更新 DOM，以 transform 移動圓牌，仍由同一模擬時間軸控制暫停。

結果標題使用九組既有我方視角名稱，棕色描邊；克制為水藍，受剋為紅，平手為米白。移除原 Canvas 中央字樣／弧線及下方結果小框。升變特寫先壓黑、高光我方，光暈位於人物背後；結果徽記閃爍兩次後轉成升變徽記，顯示棕框金字標題。

動畫由同一份 phaseTime 推進，暫停和存檔恢復不靠獨立 CSS 計時；每回合只結算一次。揭招期間 HUD 使用出招前快照，交鋒命中時再換成結算後數值。

振臂素材目前接主角、夏侯惇、于禁、郭嘉及大眾臉五組既有指揮官圖集。其他武將尚無振臂圖集，目前以本人休養動作配聚焦光暈呈現，需另補專屬振臂素材。

可重現驗收：`?art=confrontation-demo&seed=1596`，開始單挑後首合選攻擊觸發「攻其不備」；選防守可看紅字「受激失守」。seed 僅控制隔離 Demo 的假資料，不改正式战鬥 RNG 或規則。

驗證包含演出順序、有無升變、暫停、只結算一次、正式戰鬥讀檔與戰場計時凍結。實際瀏覽器檢查指令、結果徽記、水藍／紅／金字標題與主角振臂。

人物維持戰場將領比例：單挑人物在戰場比例基礎放大 1.5 倍：有效圖格尺度 324px（加兵器留白後容器 405px），振臂 277.5px。待機中心距離 345px；交鋒依目標動作決定距離：攻擊對休養／昏厥 123px、攻擊對防守 174px、雙方攻擊 234px；雙方攻擊時各走一半，接觸短停後受擊方後仰退開，再回原位。只有實際交鋒階段移動，揭招與升變仍保持站位。命中閃光與 HUD 結算同在交鋒 0.75 秒。

攻擊演出的 0.75 秒命中點使用第 2 號伸展影格並短停，第 6 號舉槍影格延至收招。命中後才切受擊，不以均速播完整圖集推算命中姿勢。

防守成功使用持續架勢，攻擊方接觸後彈退並播失衡動作；兩成承傷仍由模型正常結算，但不再把成功防守者切到失敗受擊。圖集保留每格完整美術，移除僅保留最大連通區的清理，避免分離的槍頭和刀光被刪除。

圖集抽取左右各延伸 18% 取回畫進間隔的槍尖；輸出格改為 320px，追加透明邊距，保持角色原縮放與脚底位置。保留中央人物相連兵器和格內分離筆畫，排除延伸區中的相鄰人物；動作檢視頁同步依實際格尺寸取樣。
