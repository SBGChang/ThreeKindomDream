# 新版人物與行旅配置方向

使用者已認可配置示意的人物長相，要求全人物重繪。保留原人物素材，新版另存 `public/art/characters-v2/`，已接入正式遊戲人物與頭像映射，並完成行旅訓練畫面配置。

## 配置修正

右側為「目前選中行動的共同參與者名單」，不是固定的全體同行名士。此區同時標示該行動是否有「事件」及「委託」；若資料沒有明確關聯到個別人物，狀態放在區塊層级，不擅自歸因給某個人物。
