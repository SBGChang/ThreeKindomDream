# 行動演出與能力成長

固定行動按下即執行一次規則結算，呈現層保存結算前後的能力、剩餘經驗及學習點快照。依序播放 2.6 秒任務演出、0.4 秒介面回場、0.8 秒成長灌注與 0.45 秒結果停留，再公開人物事件或推進回合並儲存。演出期間鎖定滑鼠、鍵盤與選單操作。

成長條代表升到下一點能力所需的經驗。以 Session.attrCost 逐級還原真實消耗，跨級時條重置、能力數字放大閃亮，再灌注剩餘經驗；達上限時維持滿條。學習點由前值逐步增加至結算值。

任務使用現有人物的 Q 版立繪配合位移、搖擺及道具動畫。舞台依治軍、演武、讀書／經商、治事／開墾切換；支援降低動態效果的系統偏好。

模擬策略及 Session 的訓練公式不變，CLI 模擬不經過動畫。人物事件選項本身仍維持即時結算。
