# 大檢定戰場

出陣後選擇「再打一關（演出）」會切換到獨立橫向戰場。兩軍使用 SVG 士兵、主將與指揮官面板，依實際戰報播放衝鋒、火計、水計、增益、治療及壓制。命中後才更新兵量並呈現閃光、傷害數字與士兵倒下。

## 兵量比例

每場固定採用 `ceil(max(我軍上限, 敵軍初始兵量) / 96)` 作為每名圖示代表的兵量，最低為 1。雙方共用比例，單邊通常最多 96 名；尾數以透明度表示。傷亡會減少圖示，治療會補回，並非固定人數的裝飾。主將另作角色標記，不計入兵量圖示。

## 播放與規則

- 支援暫停、下一拍、1／2／4 倍速、跳到結果及回到戰役。
- 每筆戰報分成準備、命中、收勢三拍；暫停逐拍時顯示靜態特效供檢視。
- `Session.engage` 先產生唯一戰果，畫面只依 `BattleLogEntry` 播放，不重新抽技能或計算傷害。跳過、倍速均不改變結果。
- 高速策略管道維持 `npm run sim:fast -- 100 flag-chaser`，完全跳過演出。
- 目前採用共用 2D 士兵與技能類別特效；並非每位武將獨立的專屬動畫。戰場背景沿用使用者指定參考專案素材。

純函式測試檢查兩軍同比例、兵量尾數、治療補回及命中前後戰報數值。正式 UI 另以獨立測試存檔驗證出陣、暫停、逐拍、跳到结果和返回戰役。

## 連續出征流程

戰前確認配置後直接播放第一關；正式玩家畫面取消關卡選單、掃蕩與立即結算切換。每關勝利先播放全軍歡呼，再出現撤軍／繼續選項。繼續時部隊向右跑出、畫面淡出落幕、敵軍就位開幕，我軍從左側跑入後自動戰鬥。撤軍時部隊轉身向左退場，再顯示本次通關數與實際入帳的經驗、學習點。七關全破提供凱旋撤軍；戰敗自動退場並顯示減半後獎勵。

勝利待決存檔重開時從最後一關戰報恢復走留畫面，不自動攻打下一關。動畫期間關閉遊戲仍採用已保存的真實戰果。`CampaignJourney` 只控制演出順序；高速模擬仍可直接使用 `Session`，不需等待轉場。
