# 曹操拆件動畫試作

開啟 `http://127.0.0.1:5186/?art=rig`，可切換呼吸待機、指揮手勢、暫停與六件拆解。

圖集：`public/art/rigs/caocao/parts-v1.png`。生成提示詞、來源和裁切區域見 `caocao-rig-manifest.json`。以認可的新版曹操為參考，補畫被遮住的肩部、軀幹及披風。

六件為頭、軀幹、指揮手、另一手、雙腿、披風。Canvas 在載入時去除洋紅底並裁切；使用各部件旋轉中心，製作呼吸起伏、頭部輕擺、披風擺動和指揮動作。暫停保留動畫時間。尊重減少動態效果設定。

這是遊戲內的切圖關節試作，未輸出 Spine skeleton 或 Live2D Cubism 工程；未製作網格變形、眨眼、嘴型與轉面。平面立繪不能直接得到遮擋區域，正式擴充動作仍需補件。

當選中行動的第一位參與者為曹操時，中央人物使用此動畫；其他角色保持新版靜態立繪。
