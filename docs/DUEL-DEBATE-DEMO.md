# 陣前單挑正式整合與試玩

2026-09-15。單挑已接入正式章末即時戰役，與假資料試玩共用結算、演出及操作介面。`?art=confrontation-demo` 保留獨立記憶體測試，不讀寫正式存檔；`?art=duel-motion` 可逐格檢視所有武將。舌戰仍保留原型，尚未啟用於正式戰役。

## 正式資料與存檔

我方從主角與本次出戰的同行武將中選武力最高者；同值優先主角、再依出戰順序。主角讀取當前養成數值與已裝備特性；同行讀取其人物定義，採第一項有單挑對應的特性。敵方使用當波武將數值與專屬動作；無名部隊使用陣營指揮官。無名指揮官武／統基準依章為 43、51、59、67、75、83、90、90，後續沿用 90。

特性對應由 `TraitDef.duelTrait` 配置：膽識／萬人敵→乘勝，沉毅／臨陣→沉毅，練達／折衝→調息，機敏／料敵／警衛→借勢。尚未對應的特性不追加單挑效果。能力等級、天命不另加隱藏單挑倍率。

正式觸發暫採每 8 秒交戰擲 18%，每波最多一次，僅觸發單挑。戰場時間、CD、軍糧、傷害在單挑期間停住。進度儲存在 `CampaignState.confrontation`，保留亂數、敵方預先鎖定動作、交鋒歷史、體力、傷勢與演出階段。讀檔先暫停，恢復後接續，不重擲。舊版已在進行的戰役沿用原流程，新開戰役才附加此狀態。

## 共通流程

交戰 → 凍結戰場時間、技能 CD、軍糧恢復與士兵傷害 → 兩軍淡出 → 代表左右入場 → 對決 → 勝負定格 → 全軍淡入 → 敗方全軍撤退 → 勝方全體歡呼。

我方勝利直接贏下當前一波，追擊跑出右側、壓黑、下一波入場、拉鏡、START，開始跑動後恢復計時。我方失敗則全軍撤退，結束本次出征。勝方不補兵；撤退者仍活著，不用死亡閃光；「擊退」包括撤離兵力。

單挑出招不限時，最多 24 合，血量歸零者敗。到合數上限尚未分勝負，比較剩餘血量占個人上限比例，較高者勝；相同則和局，各自歸陣，原波戰鬥繼續，不給勝利或擊退獎勵，也不再次觸發本波對決。

## 單挑：同時選招

攻擊剋休養、休養剋防守、防守剋攻擊。敵方在玩家選招之前鎖定動作；只參考公開體力、上一動作、連用次數與特性，不讀取玩家本次選項。玩家選招不限時，不會逾時自動休養，沒有精準按鍵加傷；昏厥仍自動跳過一合並恢復體力。滑鼠或鍵盤 1／2／3 出招。

體力用於行動；血量受擊遞減，歸零落敗。休養不回復血量。存檔沿用累積傷勢欄位，顯示血量＝傷勢上限−累積傷勢，舊進度可直接接續。

| 我方／敵方 | 攻擊 | 防守 | 休養 |
|---|---|---|---|
| 攻擊 | 雙方傷害抵銷，差額打在較弱方 | 攻擊付雙倍體力，防守承受 20% 傷害 | 休養被打斷，承受完整傷害 |
| 防守 | 承受 20% 傷害，敵方付雙倍體力 | 各自正常扣防守體力 | 被嘲諷，下回合禁防 |
| 休養 | 無法恢復體力，承受完整傷害 | 正常恢復並嘲諷對方 | 各自正常恢復體力 |

### 首版平衡設定

- 攻擊耗 24 體力；防守耗 12；休養隨統率變化，預設恢復 29。
- 不足基本費用不能選。攻擊遇防守的額外消耗在揭招後扣，因此剩 24–47 體力仍能攻擊，但被擋後可能歸零。
- 回合結束時體力低於 **5** 昏厥（原提案門檻缺字，本版採此值）。下一回合不能行動，恢復 24 體力，仍能受傷；昏厥不算休養，不觸發攻其不備。
- 未被克制 Combo +1，克制 +2；被克制或昏厥跳過回合歸零。最多 6，每層攻擊 +4%、防禦 +3%。新 Combo 下回合生效。
- N 是連續使用同動作的次數：第二次 N=2，第三次 N=3，最高 5。僅與上次動作相同才得動作點；未被克制 +N，克制 +2N，被克制不加。換招重算連用次數，已存點數保留。
- 攻／防／休各自最多 12 點。升變機率 = 8% + 對應點數 × 2.5 個百分點；無特性最高 38%，機率硬上限 50%。只在克制時擲骰，新得點數不影響本次機率。

| 升變 | 條件 | 效果 |
|---|---|---|
| 攻其不備 | 攻擊剋休養 | 完整傷害再乘 1.2 |
| 蓄勢待發 | 休養剋防守 | 本次恢復乘 1.5，仍受體力上限限制 |
| 借力打力 | 防守剋攻擊 | 免本次防守費、免傷並完整反彈；攻擊者仍耗雙倍體力 |

完整傷害含人物與 Combo 防禦減傷，未套用防守動作的 20%。反彈使用這個完整傷害，不重算第二次防禦減傷或反彈循環。

### 人物數值與特性

選擇頁可分別修改敵我武力、統率（1–100）及一個特性。雙方用同一套公式。

| 數值 | 公式 |
|---|---|
| 攻擊 | 18 + 武 × 0.32 |
| 防禦 | 6 + 統 × 0.16 |
| 最大體力 | 80 + round(統 × 0.4) |
| 血量上限 | 100 + round(統 × 0.2) |
| 休養恢復 | 24 + round(統 × 0.08) |
| 完整傷害 | max(1, round(攻擊威力 ÷ (1 + 對方防禦威力 / 100))) |

攻防威力含出招前 Combo。預設武 70／統 65：攻擊 40.4、防禦 16.4、體力 106、血量上限 113、恢復 29。

| 特性 | 實際效果 |
|---|---|
| 無特性 | 基準比較 |
| 乘勝 | 出招前 Combo ≥ 4，攻擊威力 +12% |
| 沉毅 | 防守體力費 12 → 9 |
| 調息 | 未受克制的休養基礎恢復 +6，可再乘蓄勢待發倍率 |
| 借勢 | 借力打力機率 +8 個百分點，滿點 46% |

以上效果在正式戰役及試玩中共用同一模型。試玩可獨立修改雙方人物、武力、統率與特性，不影響正式養成。

## 舌戰：原型保留

郭嘉對敵軍指揮官，雙方信念 100。最多五次交鋒，每題 14 秒，三個回應位置洗牌；正確敵方 -34，錯誤或逾時我方 -30。兩次洞察（Q）提示破綻，同題不可重複。到上限比剩餘信念，同分敵方守住陣線、我方挑戰失敗。

五題涵蓋補給實情、兵力證據、承諾條件、共同目標、前後矛盾。仍是入門內容，尚未把單挑數值或動作系統套到舌戰。

## 觸發與操作

試玩單挑、舌戰按鈕在每波實際交戰 3.5 秒後必定觸發。試玩的自然模式每累積 8 秒戰鬥時間擲 18%，兩模式各半，每波最多一次，沒有保底；正式模式的相同機率僅抽單挑。

入場、技能鏡頭、換關與暫停不累積觸發時間；戰役到時不觸發。右鍵、Esc、Space 暫停；切離分頁自動暫停，須手動恢復。暫停鎖定操作和思考倒數。

## 測試與限制

`npm run verify:confrontation` 驗證九組出招、三種升變、禁防到期、體力限制、昏厥、Combo／點數／連用上限、數值與特性、和局及戰場勝負流程；並執行 **7,800 場**固定種子的完整單挑。

每組 600 場，敵方武 70／統 65／無特性。以下是固定策略對本版 AI 的測試，不是人類玩家勝率或正式平衡保證。

| 我方策略（武 70／統 65，無特性） | 勝率 |
|---|---:|
| 優先攻擊，付不起時休養 | 38.0% |
| 優先防守，不能防時休養 | 14.0% |
| 一直休養 | 0% |
| 攻防休輪替 | 37.0% |
| 按公開體力的混合策略 | 45.0% |

同混合策略、種子及統率，武力 45／70／95 勝率為 28.3%／45.0%／55.0%。武 70 同條件特性比較：乘勝 46.7%、沉毅 51.7%、調息 48.2%、借勢 47.8%。這不是正式角色評級，仍需真人試玩及角色配置測試。

模擬發現舊 AI 面對昏厥或無法攻防者仍常防守，導致無腦攻擊偏強；現版依公開可用動作抓破綻，不讀取本次選招。

## 動作與美術 UI

目前 38 個身份各有專屬整張騎乘序列：攻擊、防守、休養、受擊，每種八格，合計 1,216 個使用影格；不使用拆肢骨架。四種動作播放一次後停格，攻擊先出招、受傷者接受擊。嘲諷與反彈沿用對應防守／休養動作，加升變特效與狀態章。

素材在 `public/art/duel`，生成提示與版本在 `docs/art/duel-prompts`。郭嘉、華雄來源為八欄八列，選取四段完整八格動作；其他使用四欄八列。執行時去除洋紅底、鄰格孤立碎片，保持原比例並統一落地基線，武器與身體保持整張連接。

UI 使用独立繪製的紅劍／藍盾／綠茶令牌、相剋輪盤及人物狀態卷軸。交鋒錄以同一套圖示記錄双方出招，亮框標示克制方，箭頭表示方向，六合一頁可翻閱。詳細規則收在問號；主畫面僅保留數值、短標籤與狀態。

`verify:confrontation` 同時檢查所有內容人物／有名敵將的素材覆蓋。`verify:realtime` 檢查正式數值接入、禁止戰法、凍結計時、單挑存取與重複結算防護。

## 單挑 UI 優化第一版（2026-09-15）

入口仍為 `?art=confrontation-demo`，選「單挑」。本次共用 DuelHud 同時套用獨立 Demo 及正式戰役單挑覆蓋層。

- 上方格鬥 HUD：外側圓形金框頭像、向場中延伸的長紅血條、下方較短的藍體力條，Combo 位於頭像下方。敵方鏡像排列。保留武統、特性與禁防／昏厥狀態；結果以心形圖示與負值表示扣血。

- 右側：選取後才展開三種敵招推演，先敵後我排列變化量。最近四合出招收於 H 規則視窗，以上敵下我排列，亮框加「剋」標記，可翻頁。
- 規則改為三組圖示配對，按說明時暫停模擬；關閉只在原本運行時恢復。說明內 Escape／右鍵關閉，Tab 留在視窗內，不讓背景操作干擾對局。
- 選招時壓黑戰場，指令維持高光；Hover 保持圖示位置與比例，僅亮框並觸發 HUD 預览。

新增美術為 `public/art/duel/status-icons-v1.png`（綠色體力晶、繃帶傷勢盾、連勢火焰、昏厥星環），內建 imagegen 生成，提示詞保存於 `docs/art/duel-status-icons-prompt.txt`。檢查為 RGBA，外角透明；透過既有 DuelArt 圖集載入。

結算記錄新增可選 `changes`，記錄受上限與零值限制後的實際體力／傷勢變化。例如僅剩 24 體力，攻擊遇防守的名目成本為 48，介面實際顯示 −24。舊存檔缺少此欄仍可讀取，沿用舊紀錄的成本／恢復數值；新欄位經存檔驗證。這不改變傷害、成本、AI、機率或結局規則。

本次 HUD 驗收增加五分鐘不出招仍停留原回合、敵招不重擲、戰場時間與補給凍結、昏厥自動跳合、舌戰仍維持原倒數，以及血量由滿至零／休養不補血測試。頭像重用既有角色美術；夏侯淵使用其專屬單挑圖集的頭部，血量圖示重用舌戰心形美術。

## 三指令轉盤與出招推演（2026-09-15）

選招時壓黑戰場，左側只顯示攻擊／防守／休養轉盤與有方向的相剋線。點一下或數字 1／2／3 只選取指令，右側才展開敵招推演；中央「出招」或 Enter 確認。右鍵／Esc 優先收起選取，再次操作才暫停。出招後移除決策壓黑與轉盤，交鋒演完再回到未選取狀態。紀錄收於 H 開啟的規則與出招紀錄內。

Hover、鍵盤聚焦或點擊敵招會高光雙方 HUD，在實際條槽上疊半透明脈動區段：水藍＝可能增加，紅＝可能損失；旁邊顯示本次差額。預覽共用 resolveRound 的實際結算，分別計算一般／升變兩條分支，顯示範圍，不暴露實際升變亂數或未看破的敵招；不寫存檔、不消耗亂數、不變更正式狀態。禁防、體力不足等不可能敵招不可推演；昏厥改顯示停動恢復。

動作點改成指令周圍的呼吸光暈。0 點微光，點數提升逐步加強、加快；12 點滿點為強光暈，精確點數保留在 tooltip，所選動作升變率在右側顯示。

武力看破：我方武力至少高 20 點時，每合有 30% 機率給出已鎖定敵招的可能動向提示；之後每多 1 點差距加 1.5 個百分點，最高 75%。提示採當合狀態雜湊，同合 Hover、重選與存讀檔不重擲，也不改變戰鬥 RNG。提示在轉盤與敵招圓框右上使用敵將小頭像。未觸發提示仍可自由比較三種假設。

驗證包括九種對局的一般與升變範圍、上下限、昏厥、禁招、真正結算落於預覽區間、預覽不讀取實際敵招／亂數、提示條件與同合穩定性；7,800 場原單挑規則模擬仍通過。

## HUD 攻防讀值（2026-09-15）

單挑上方 HUD 上移，將武／統原始值改為刀圖示＋攻擊力、盾圖示＋防禦力。直接讀取 attackPower／defensePower，包含當前 Combo 與攻擊特性效果，以最多一位小數顯示；攻擊數字紅色、防禦數字水藍色，均有棕色描邊。這是攻防能力值，實際傷害仍依對方防禦、相剋與升變結算。試配區保留武／統輸入作為測試資料來源。

依補充標記移除單挑頂部標題、關卡資訊、暫停按鈕與中央回合／提示／問號，HUD 靠近上緣。攻防圖示緊接人物名字，敵方鏡像。Esc／右鍵仍可暫停，H 開啟規則與出招紀錄；Demo 的戰場返回連結收至暫停選單。

損失預覽時，依可能損失區段裁掉原實色條，只留下槽底與半透明紅色閃爍段；敵方反向裁切。移開推演便立即恢復原條，實際數值不變；恢復預覽維持原條並於末端追加水藍段。
