## 預計優化方向

| 項目 | 建議 | 原因與限制 |
| --- | --- | --- |
| 同框 | 條件寫「與此武將一同修練時」；效果分類暫稱「指導加成」 | 用玩家行為描述，避免把畫面位置當成遊戲術語。名稱待討論。 |
| 武格／智格／該維 | 改為「武力修練／智力修練／本次修練的屬性」 | 讓玩家直接知道作用對象。 |
| 基礎成長 | 主文可用「基礎經驗」，詳情提供小數成長對照 | 是否保留雙單位，待討論。需和直接屬性增加分開。 |
| 隱藏條件 | 說明參與修練、好感階段、星級、持有道具等實際條件 | 名士的站位效果有好感門檻，道具加成沒有同一門檻；不應只寫「在隊伍中」。門檻從資料取得。 |
| 再增加／疊加 | 統一每階新增量與目前累計效果的呈現 | 「再 +」是新增一條效果；加法、乘法、上限不可混為一談。 |
| 權重／機率 | 主文用「更容易參與武力修練」等描述，詳情保留相對權重 | 權重 10→15 不等於出現機率 10%→15%。 |
| 保底光階／升階 | 換成與修練畫面一致的品質名稱及明確時機 | 區分最低品質提高與額外升級機率。 |
| 加成／收益 | 分清基礎經驗、最終經驗、文功、武功、好感與戰鬥效果 | 指導倍率還經換算及上限，不能直接宣稱最終經驗增加相同百分比。 |

## 建議文案結構

採用「條件 → 作用對象 → 效果與單位」，一行只說一件事。共用規則集中放在說明區，不在每條重複長篇公式。

夏侯惇範例（草案）：

> 與夏侯惇一同進行武力修練時，基礎經驗增加 8。

另列實際好感生效條件；共用說明標示「基礎經驗仍受修練倍率與高屬性成長衰減影響」。

優先討論：採用「一同修練／指導」還是「共同修練／協作」；主文採經驗單位，或保留小數與經驗雙單位。
