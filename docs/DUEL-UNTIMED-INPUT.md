# 單挑不限時輸入

一般單挑選招階段從計時更新流程提前返回，phaseTime、elapsed、戰場與單挑狀態均保持不變。時間經過不能提交指令；明確確認出招才進入交鋒。只有已昏厥的回合保留 0.8 秒後跳過行動與回體的規則。舌戰的既有計時不受影響。

replyWindow 與舊 timeout 入口同時依單挑資料和種類封鎖超时，防止舊狀態誤入其他計時分支。

驗證：初次等待五分鐘、第二合等待十分鐘、舊狀態已有一小時計時與已選項、非昏厥低體力、正式戰鬥存檔恢復等待五分鐘，皆無自動出招。瀏覽器選擇攻擊後等待約 97 秒，仍在 read、血量與體力不變；按出招後才进入 clash。相關戰鬥測試與正式建置通過。

此次未重現使用者先前畫面中的自動出招原因；已強化一般選招和計時的隔離，昏厥路徑仍依原規則保留。
