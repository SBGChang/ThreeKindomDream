# 魏國天命經濟 v3：長線養成

狀態：設計與算術驗算，尚未套用正式遊戲。本文件取代 `WEI-V2-NUMERICAL-DESIGN.md` 第 8 節的天命收入與定價；其他 v2 規則仍需一起落地。參數見 `balance/wei-destiny-v3.proposal.json`，執行 `npx tsx scripts/destiny-economy-audit.ts` 可重算，結果在 `balance/wei-destiny-v3.audit.json`。

## 目前問題

現行結算為 `(文武官階合計×150＋過章×250＋回合×12＋圓夢1200)×結局倍率`。文武各 5 階、4 章、32 回合、棟樑倍率 2，即得 8168 點。現行「棟樑」只需文武各 5 階，零天命也可能到達。

實際跑 100 個獨立零天命帳號、seed 1000–1099、flag-chaser 策略，中位數 8168、平均 7840.4、最低 5088、最高 8168。這是現行規則的固定策略模擬，不是玩家遙測，也不是買完升級後繼續下一輪的連續帳號模擬。

現行資質點買滿 5000、天賦點 3050、天賦解鎖 4450，三者合計 12500；兩次 8168 足夠。整店實際 70900，不能據此說現在整店必然兩三輪全滿。問題是常用的成長線太早買完，並且通關倍率放大所有收入，官階解鎖同時增加戰力、局內報酬與跨輪收入。

## 目標

- 第 1–3 輪：每輪能買 1–3 個便宜階段，開始選方向。
- 第 4–12 輪：主力武將升至 3–5 星，天命仍有大額目標。
- 單一武將五星仍需最低 12 次滿額同行；第 13 輪才能帶五星入夢。六人可同期成長。
- 第 14–20 輪：主方向的能力上限與官途資金大致到位。
- 第 16–22 輪：再補一套天賦配置的資金。這是購買力目標，不保證最好結局；實際還需能力、技能、事件和深關條件。
- 約第 49–65 輪：商店全收集，參考路徑 53 輪。後半以換流派、不同人物結局與收集為主，不應讓第一次好結局等到全商店買滿。

## 每輪天命結算

`天命點 = 完整生涯400 + 實際行動×5 + 完成章數×50 + 文武最終官階合計×10 + 本輪各章通關數合計×10 + 結局固定獎勵`

- 完整生涯：走完四章，不要求高階結局；戰敗仍可完成生涯。
- 實際行動以 actions 四維總和計，最多 32；不要使用可能是游標的 turn 代替。
- 官階各最多 12、章數最多 4、關卡總數最多 28，每章每關只記一次。
- 通關紀錄無論後來撤軍或戰敗都保留；戰役經驗的減半不再減掉天命的通關紀錄，避免失敗双重扣款。
- 結局獎勵：白身／罷官／普通 0，文臣／武將 100，丞相／大將軍 200，最好結局 300。每次完整結算可領，不設首通巨額貨幣。
- 中途放棄只計已完成行動、章節、官階與通關紀錄，不給完整生涯或結局獎勵。不能先領一部分再完整重領；每個 runId 只入帳一次。
- 不出售天命收益倍率，不让道具、活動或結局把整筆收入翻倍。四章版本每輪理論最高 1580，這是各項上限的合計，不是先算完再偷偷裁切。
- 既有 `RunSummary.stagesCleared` 只讀當下 campaign，不能當作四章總和。正式實作需保存各章唯一通關紀錄。

| 起步 | 6 | 12 | 0 | 940 |
| 初成 | 8 | 14 | 100 | 1080 |

## 商店價格與作用

所有價格為該階單獨支付，逐階購買。

| 項目 | 各階價格 | 買滿總價 |
|---|---|---:|
| 資質配點，依序 +2/+3/+4/+5/+8/+10 | 300 / 600 / 1000 / 1500 / 2600 / 4000 | 10000 |
| 單維上限 B / A / S，四維分購 | 300 / 900 / 2400 | 四維14400 |
| 官階上限 6→12，文武共用 | 300 / 500 / 800 / 1200 / 1800 / 2400 / 3000 | 10000 |
| 天賦配置點，每階 +2，共 +10 | 500 / 1000 / 2000 / 3500 / 5000 | 12000 |
| 七項天賦解鎖 | 300 / 500 / 800 / 1200 / 1800 / 2600 / 3600 | 10800 |
| 光階改善五階 | 600 / 1200 / 2200 / 3600 / 5400 | 13000 |
| 魏國初遇人選擴充三階 | 500 / 1000 / 2000 | 3500 |
| **總額** | | **73700** |

商店總額與原本接近，重點是收入降到可控制區間，以及把原本過便宜的配置點與天賦線拉長。官階頂階反而降價，避免把大筆預算鎖在同一項功能。

光階改善需重新配效果，平均額外成長依序 +1/+2/+3/+4/+5%，不要把此數字乘在舊光階加成之上；與其他非武將永久增益共用 v2 的額外成長 +10% 預算。最高階是追求完整，不應成為通關必需。

初遇人選擴充取代原本付費指定上司的勢力緣分：每階增加一位「初次招募時可選候選人」，最多 +3，不新增同行或上司席次。已認識且完成同行條件的人，重複邀請免費，不收每輪門票，也不販售碎片加速。

天賦配置點加到 10 後，正式落地前須核對所有天賦配置成本與疊加上限；本輪只提出貨幣預算，不沿用可能破壞成長預算的舊效果。

## 核心購買力與輪數

三維 A、一維 B 的資質配點需要 32 點（9+9+9+5），商店總配點也為 32；買到四維 S 解鎖不等於有 56 配點可同時選四個 S。

- 資質配點買滿 10000＋三個 A 與一個 B 解鎖 3900＋官階上限買至10階 4600＝**18500**。
- 再預留天賦配置前兩階 1500＋前三項天賦解鎖 1600，成熟配置資金為 **21600**。這只是一條指定預算，不宣稱這三項適合每個流派。
- 以上成本不包含全買其他項目。若先買光階或全維 S，核心到位時間會推遲；配置選錯應允許免費重配已買配點，不能靠反覆收費延長遊戲。

| 收入情境 | 核心18500到位 | 成熟預算21600到位 | 全店73700 |
|---|---:|---:|---:|
| 參考收入×0.8 | 20輪 | 22輪 | 65輪 |
| 參考收入 | 16輪 | 19輪 | 53輪 |
| 參考收入×1.2（不超過1580） | 14輪 | 16輪 | 49輪 |

算術採逐輪收入加總，不是用最後一輪高收入乘所有輪次。第1–2輪940、第3–4輪1080、第5–7輪1120、第8–12輪1160、第13–18輪1340、第19輪起1520；固定假設，不是閉環成長模擬。±20% 是資金壓力測試，非玩家分位數。

參考第3/7/12/16/19輪累計產出為2960/7400/13200/18560/22760。即使假设從第一輪都拿理論極限，零初始資金买滿也需 `ceil(73700/1580)=47` 輪；前三輪最多4740，不足商店的7%。外部贈點、折扣與舊檔資金會破壞這個下限，故不得另行無預算贈送。

## 正式落地與驗收

先一起更新 v2 的武將碎片、經驗來源、戰役強度、最好結局門檻，以及本方案的收入與商品效果；只改價格無法修正零星就大量取得最好結局的現狀。

接著使用同一個帳號跨輪：實際結算→依購買策略買天命→選人與配點→下一輪。至少測保守、專精、平均購買、亂買及追最好結局策略，各跑多組種子。紀錄每輪收入、每項購買、主力星階、各章深度、首次最好結局、全店買滿輪數與實際每輪遊玩時間。若每輪30分鐘，53輪約26.5小時；每輪60分鐘則53小時，最終需以實測時間校準，不能只拉輪數。

正式門檻：任何合法新帳號三輪不可買滿；武將五星不得早於12次有效同行；前期完整一輪能買到至少一個未購低階；主配置資金落在14–22輪範圍；全店參考49–65輪。高階最後一級可能需存3–4輪，中間應有武將事件、其他角色、流派或劇情目標；若內容沒有足夠差異，寧可縮短全收集，不放空刷門檻。

舊存檔不應直接套新價格後清除已購。建議維持舊檔為舊經濟版本，另開明確標示的新平衡存檔驗證；若要正式遷移，另訂保留項目與換算規則。此提案沒有修改或重設玩家存檔。
